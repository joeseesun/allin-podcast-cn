英特尔在基辛格回锅之前的五六年里，向股东返还了 1000 亿美元，分红加回购。同一时期，这家公司十年没有建过一座新晶圆厂，也没买过一台 EUV 光刻机。

把这两个数字摆在一起，后面发生的很多事情就不用解释了。

帕特·基辛格（Pat Gelsinger）在英特尔待了 34 年，18 岁入职，中间离开去 VMware 做 CEO，2021 年回来接手这家他口中「美国历史上最伟大的公司之一」。这期 All-In，他和杰森·卡拉卡尼斯（Jason Calacanis）做了一次公开复盘，从「Intel Inside」那段叮咚声讲起，一直讲到台湾的能源储备和量子计算的时间表。

他的答案比外界想象的简单，也比外界想象的难听。

20 人的高管会里坐着 15 个博士

基辛格入职时，英特尔的管理层是戈登·摩尔（Gordon Moore）、罗伯特·诺伊斯（Bob Noyce）、安迪·格鲁夫（Andy Grove）、克雷格·巴雷特（Craig Barrett）这一批人。他开玩笑说自己「在英特尔经历了青春期」，这些人既是他的导师，也是他崇拜的对象。

他记得第一次列席高管会议，房间里 20 个人，15 个是博士。

「我认为公司跑偏的起点之一，是它开始由商业人士管理，而不是技术人员。是那些算账的人，财务的人。2021 年我接任 CEO 时，这是这家公司大约 15 年来第一位技术出身的掌门人。」（基辛格）

他补了一句更狠的：一个商务出身的领导，会提拔什么样的领导？还是商务出身的。

杰森顺着问，那今天活得好好的科技巨头怎么解释。基辛格的答案是，它们都很技术，而且大多是创始人主导。萨提亚·纳德拉不是创始人，桑达尔·皮查伊也不是，但两个人都是深度技术背景。

理由在决策的性质。当你要做的是影响几十亿美元的技术判断，你没法靠一张电子表格做决定。表格会告诉你这个项目回报率不行，不会告诉你技术趋势会让这个回报率在五年后变成一个笑话。

1000 亿美元还给股东，十年没建一座新厂

杰森问他，那 1000 亿美元如果留在资产负债表上，你会拿来干什么。

「大概会给 iPhone 做芯片吧，那个单子英特尔当初放弃了。」（基辛格）

他接着说，2021 年他回到英特尔时，这家公司已经十年没建新厂。不建厂，不买 EUV，这些决定单看经济学都不划算，只有技术出身的人才会顶着财务部门的反对去做，因为他知道不做的代价在十年后。

杰森拿苹果做对照。苹果过去 15 年也在疯狂回购、大额分红，是全世界持有资本最多的公司之一，收购全是边缘上的小买卖，最大一笔是 Beats，目的还是打进它进不去的安卓用户群。杰森的评价是：这是一场巨大的浪费，苹果本可以做很多了不起的事。

然后他问起 2008、2009 年乔布斯决定自研芯片，英特尔当时知道吗。

基辛格的回答绕了一下。乔布斯是了不起的领导者，也是无情的领导者，很难搞。苹果转向英特尔和 Centrino 芯片那件事当年很大，苹果对英特尔提的要求也极高：芯片再小一点，功耗再低一点，是个苛刻到极致的客户。

当乔布斯不再相信英特尔能继续做到这些，自研项目就启动了。苹果先收购了 P.A. Semi 这类小公司，做几颗不起眼的小芯片，然后小芯片一点点变大。

乔布斯：过去四个版本我一直在往 x86 上移植

基辛格讲了一段对话，是这期节目里最有画面感的细节。

当年苹果要把操作系统从 Power 架构迁到英特尔，英特尔这边挺自豪，觉得自己在芯片、软件、编译器、操作系统上的积累都够深，于是主动提出：史蒂夫，我们可以帮你把操作系统移植到 x86 上。

「乔布斯说，过去四个版本我一直在做这件事。」（基辛格）

基辛格说他当时就愣住了。苹果内部早就把核心技术在往 x86 上准备，只是外面没人知道。这件事提前好几年就埋好了伏笔。

他给这件事的定性很克制。乔布斯从来没说过「你作为供应商不合格」，他的判断是「我能更好地供应我自己」。苹果想要的是把系统设计和芯片设计放在一起优化，不再依赖一颗为 Windows 环境优化过的芯片。

这个逻辑放在任何一家依赖单一供应商的公司身上都成立。当你的供应商开始跟不上你的产品节奏，自研的理由就变成了控制权，省钱只是顺带的。

英特尔曾经嘲笑英伟达的机器

聊到英伟达，基辛格的语气里有点自嘲。

「我们在 CPU 最强的时候，是有点看不起他那套机器的。那不就是图形卡吗，有些玩家喜欢用而已。那个年代的世界观就是，大 CPU，配几个小 GPU。」（基辛格）

转折发生在英伟达开始认真搭软件栈之后。CUDA、SIMT、多线程，一代一代往上叠，每一代都好一点点。基辛格说这种打法「有点像乔布斯」：不追求一次革命，追求每次发布都比上次强一点，然后把复利攒起来。

真正的分水岭是日本做 HPC 的那批人说，也许可以拿这些显卡跑高性能计算。从那一刻起，它不再是一张图形卡，而是计算密度更高的平台，可以去啃世界上最有意思的那批负载。

基辛格在英特尔内部推过一个叫 Larrabee 的项目，思路是用 x86 去做同样的事。他第一次离开英特尔，一周之后项目被砍。

「如果那个项目活下来，世界会完全不一样。」（基辛格）

他引用威廉·吉布森那句「街道会为技术找到自己的用途」。英伟达没预测到比特币会用显卡挖矿，也没预测到 AI 会起飞，但因为它是当时最好的解法，黑客社区自己找了上去。

这段话其实在说一件更普遍的事：平台的价值不由创造者定义，由使用者的想象力定义。你能做的只是把通用性做到极致，然后等别人来发现用途。

台积电把这件事砍成两半

第三个分岔口是台积电。

台积电一开始的愿景就是纯代工：我不设计，我做整个行业的工厂。这门生意门槛极高，一座厂两三百亿美元，还要持续的工程投入和产能更新。

英特尔走的是另一条路，业界叫 IDM，设计与制造一体。它从来不把工艺和产能开放给第三方。基辛格解释得很直白：英特尔自己的 CPU 用量就够大，工艺还能复用到芯片组和其他产品上，从来没做过标准化，没有 PDK，没有对外设计工具链。英特尔甚至自己做 EDA，基辛格早年就参与过这门技术的基础建设，第一个布局布线工具、第一批标准单元、第一个高层描述语言，全是自家闭环里的东西。

「太专有了。台积电等于是把这件事从中间砍断，说我不在乎是谁的芯片，我不在乎你在设计什么，我当你的制造伙伴。」（基辛格）

当年这块业务小到英特尔根本懒得看。等到苹果成为台积电的大客户，一路把它推上去，行业规则就改了。

规模差距的数字最能说明问题。2021 年基辛格回到英特尔时，台积电的晶圆产出是英特尔的五倍。不是多 10%，是五倍。现在这个比例到了七比一。

代工成了半导体行业的默认模式，只剩两个例外：英特尔和存储。存储公司坚持自己设计自己制造，跑出了市值万亿级别的巨头，台积电自己也成了一万亿美元的公司。整个行业选择的是：我要大量晶圆，我要各种不同设计的创新，中间隔一层标准化和 EDA 工具。

基辛格回到英特尔后的核心战略之一，就是把英特尔也变成代工厂。

台湾的能源储备不到三周

杰森问起《芯片法案》的进展，以及台湾的风险该怎么定价。

基辛格给了三个数字。2021 年他回来时，美国占全球先进制程产能大约 12%，今天是 18%。有进步，但离 50% 还很远。英特尔开始成为一家真正的代工厂。台积电在亚利桑那的厂已经投产运行。三星也在。

然后他说，接下来这段会让人不舒服。

「台湾岛的能源储备不到三周。《华尔街日报》两周前有篇大文章讲这个。封锁三周之后，全岛开始轮流停电。而晶圆厂一旦断电停机，九十天才能恢复。台湾一次停电对全球经济的冲击，比大萧条还大。」（基辛格）

他强调，这件事用不着开一枪。只需要说一句：三周没有能源，没有油，没有液化天然气。这座岛就是这么运转的。

并且封锁性质的演练已经反复发生过。他提醒听众，过去四年里，中国在台湾海峡搞过七次这类演习。至于时点是 2027、2030 还是 2035，意图在很长一段时间里已经足够清楚。

泡沫的上限写在电网里

杰森问他 AI 是不是泡沫。基辛格的回答分两层。

第一层是风险，说得很实在：这些公司的估值非常夸张。如果建得太多、花得太多、赚得不够，投资者会跑掉，公用事业股和科技股都一样，钱花得比赚得快，市场就不爱你了。

第二层是他所谓的「银 lining」：能源容量。

「全球能源容量每年增长 4% 到 5%。美国有整整十年只有 1%，我们对电网做的事很难看。但现在在补。没有电，没人会去买 GPU、建数据中心，所以泡沫的规模天然有一个上限。」（基辛格）

至于 token 的边际价值，他的判断是：如果 token 衡量的是智能，那它的价值某种程度上是无限的。更多智能意味着更好的供应链、更好的金融、更高效的物流。加上发达国家普遍缺劳动力，需求侧几乎没有天花板。

他自己的目标是把 AI 做好一万倍，具体做法是把每个 token 的成本和能耗降五个数量级，让杰文斯悖论真的发生。用得起，用得多，总量爆炸。他提到 Cerebras、Groq、dMatrix 这一批做推理芯片和推理架构的公司，都在往这个方向推。

所以他不认为这是一两年的行情，是二十年的建设期。中间会有很多次修正，每次修正都该说声谢谢，因为那是市场在防止泡沫跑到前面去。他管这叫「SaaS 末日」那一类事件，后面还会有很多次。

量子计算他给了明确时间表：这个十年内会有实质结果，2028 到 2030 之间，物流、化学、生物这些今天算不出来的问题会被算出来。至于破解现有加密体系的 Q-Day，大概在 2032 到 2033。作为 PsiQuantum 的投资人，他说现在的状态是，怎么造量子比特、怎么做纠错、怎么设计算法都清楚了，剩下的是工程规模化。离子阱、光量子、自旋等四五种模态都跑出了不错的结果，纠错在每种模态上都被验证过。

「人类历史上，没有哪个时刻比现在更适合当一名技术人员。」（基辛格）

每周一百万个新项目

节目的后半段，杰森请来了 Lovable 的创始人安东·奥西卡（Anton Osika）。杰森开场就说，这是他最喜欢的创始人之一，因为产品让他手下的团队上了瘾。

奥西卡把公司的使命拆成两道坎：第一道是让人能做出产品，第二道是让人能围绕产品做出生意。第一道他们走了很远，第二道正在投重注。

数字很密。平台上每周有 100 万个新项目被创建，累计超过 5000 万个应用，这些应用每月被访问超过 7 亿次。公司进入市场才 20 个月。杰森以为年收入是 4 亿美元，奥西卡纠正说，5 月就做到了 5 亿。

用户结构是杰森最关心的。奥西卡说大约 20% 有技术背景，工程师喜欢它是因为平台在很多架构决策上自带主张：支付怎么接、安全怎么扫、数据怎么隔离，默认就按最佳实践来，每次改动之后后台还会跑安全扫描，免费用户也跑。剩下五分之四是非技术用户。

这两拨人之间有一条通道。有人在大公司里从同事那儿听说 Lovable，回家搞副业，副业做到几十万美元年收入，然后辞职成了创始人。平台上已经有人在跑年收入超过 100 万美元的生意。

五十万美元的内网，四小时做完

杰森讲了一个自己公司的例子，比任何产品演示都有说服力。

他办了一个叫 Founder University 的预加速器，团队一直想要一个内网。放在十年前，这东西要 50 万美元，他不会批这个预算，钱应该花在创始人身上。结果负责这个项目的人自己用 Lovable 做出来了，四到八个小时，没经过他同意，刷的公司卡。

后来杰森让她再做一个东西：把这 50 家入营公司的经济影响算出来，每家公司多少人、纳多少税、房租多少、平均工资多少。她用 Lovable 加上杰森给的提示词做完了。

「这东西我根本雇不起人来做。Lovable 一个月 50 美元，商业版。起步价 25 美元。」（杰森）

他算了一笔账：两年前要 50 万美元的软件，一个员工四小时做完，加上人力和软件订阅，一年成本不到 2000 美元。99.6% 的成本就这样消失了。

从建产品到经营生意

杰森问一年后 Lovable 会是什么样。奥西卡说，构建产品这一侧的缺口他们已经填得差不多了，接下来是运营。

第一条新产品线是托管。不只是 AI 生成的那部分，还包括常规的应用托管，等于在做一个 AWS 的竞争者，底层也和 AWS 有合作。这条线的增速现在比构建产品本身还快。

第二条是「AI 联合创始人」。还在预发布阶段，逻辑是：如果你的应用和工具都跑在平台上，那平台就握着你公司的全部数据。那么一个能跟你讨论业务的 agent 就有意义了。它在你睡觉的时候工作，早上回来告诉你，这里有三个战略方向，这些是可以优化的地方。

「你是来建软件的，但你会留下来做生意。」（奥西卡）

他举了 Nursa 的例子。这家美国公司的员工 Nenad 用 Lovable 做了一条护士教育产品线，排课、执照、认证管理全在里面，产品做出来还能直接推向市场，因为公司本来就握着大量想拿认证的护士。同样的东西他还搬回了后台，替换掉 10 多个内部工具，一年省下 100 多万美元。

杰森顺势问了那个很多人都在想的问题：Slack、Salesforce、HubSpot、Office 这些基础设施，会不会被定制软件取代。奥西卡的回答不走极端。有些场景确实需要定制，因为现成工具就是不合身；但 Lovable 也会持续和这些系统互通，你可以在 Salesforce 上面叠一层自己的界面，同时保留底下的数据和流程。

多模型路由和 token 经济学

杰森提到一个说法：过去每六个月就有人宣布 Lovable 已死，因为新的基础模型太强了。然后每六个月，Lovable 的年收入就多 1 亿。

奥西卡的解释是模型策略。用户提的需求会被路由到最合适的模型，既包括多家厂商的商业前沿模型，也包括越来越多的开源权重模型。当请求落到自家模型上，那个模型会针对他们的 agent harness 变得更聪明，尤其是在「该调哪个工具、该建哪个集成、该怎么把用户带到成功」这些具体环节上。

他们在斯德哥尔摩有一支做后训练的研究团队，正在显著扩编。方法是从模型当下犯的错误里找规律，按对客户的影响排序，针对性地造数据集做强化学习。每周 100 万个新项目意味着海量的 token 消耗，也意味着海量的信号。

杰森抛出一个现象：有些公司在做 token 倾销，100 美元的 token 卖 50 美元，本质上是 token 经销商，生意是亏的。奥西卡说他们一直盯毛利，但从来没有为了便宜去选一个明显更差的模型，因为差距是可测量的。他承认有配额，最低档大约 60% 的用户会超配额付费，而愿意付的人越来越多，因为对比对象是三年前那份软件采购合同。

两个内网，两次挥棒

杰森讲了一个新出现的管理问题。他们为日本做了一个内网，美国这边有人另做了一个，现在是两套软件。他问那两个人有没有 fork 对方的代码，答案是各建各的 Lovable 项目。

放在以前的开发模式下，这种事不会发生，因为只有一条软件路线，所有需求最后都塞进同一个「科学怪人软件」里。现在变成了两条独立路线。

「我其实是快速实验的超级拥趸。自由市场之所以有效，就是因为有竞争。学术界也这么干。既然工程不再是瓶颈，瓶颈变成了『到底该建什么』，那让足够多的人从不同方向去解同一个问题，是好事。」（奥西卡）

他还给了具体的收尾办法：让一个项目去看看另一个项目，把喜欢的三点搬过来，甚至可以跑一次分桶测试，看哪个版本对客户的指标更好。

杰森最后问起 Anthropic 的新模型 Fable，网上有人用它做出了 3D 版的 Fortnite。奥西卡说 Lovable 也在用 Fable，第一版就能生成很精致的东西，3D 游戏这类任务提升明显。但「该建什么」这件事没有变得更快，人还是得和 agent 一起做规划，把正确的数据喂进去，才能做出对产品和对生意都正确的判断。

整期节目听下来，两个嘉宾讲的是同一件事的两面。基辛格在讲一家公司怎么因为放弃了技术判断而输掉二十年，奥西卡在讲当技术判断的成本降到接近于零之后，组织会发生什么变化。

  • 如果你在一家有技术底子的公司里做决策，别让财务模型单独上桌。它能算出回报率，算不出五年后这项技术会不会让回报率变成笑话。
  • 关注电力，不只是 GPU。数据中心的物理上限写在电网扩容速度里，这个变量比任何一份算力预测都硬。
  • 把台湾的能源数据放进你的风险清单：储备不到三周，晶圆厂停机后九十天才恢复。这是供应链上的具体天数，比地缘政治的抽象讨论更能指导备货和选址。
  • 别把 AI 编程当成单纯的降本工具。真正的变化是试错成本从 50 万美元掉到几千美元，这意味着你可以允许两个人从不同方向解同一个问题，然后让两个版本互相比。
  • 非技术背景的人现在就该动手。25 美元一个月的起步价说明，门槛不再是预算，而是你有没有想清楚要建什么。
  • 如果你是投资人，与其纠结「是不是泡沫」，不如盯住「什么时候修正」。能源约束决定了泡沫有顶，而每一次回调都在替你延长这场二十年的建设期。
