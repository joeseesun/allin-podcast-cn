一家普通读者可能从没听说过的公司，18 个月里融了 350 亿美元，用来建 AI 基础设施。这是 CoreWeave。它靠什么说服华尔街？答案是一个叫「盒子」的融资结构。这篇文章来自杰森·卡拉卡尼斯在 NVIDIA GTC 大会现场的连环访谈，四位 CEO 分别来自 CoreWeave、Perplexity、Mistral 和 IREN，拼在一起正好是 AI 产业从芯片到应用的一条完整链条。

CoreWeave：从天然气对冲基金到 GPU 云

迈克尔·因特拉托讲公司起源，讲得像一部歪打正着的创业史。他原本运营一家专注于天然气的算法对冲基金，算法写完之后就有大量机器闲置时间，团队开始研究加密货币。他们看了比特币挖矿，判断打不过：造 ASIC 的工程师比自己更擅长运行 ASIC。于是选了 GPU，因为 GPU 既能挖以太坊，还能干很多别的事。从第一天起，算力就被当成一个可以切换用途的期权。

公司 2017 年成立，头三年挖矿，经历了两次加密货币寒冬。因为出身对冲基金，团队对风险和资本配置的管理是刻在基因里的，所以熬得特别稳。之后用途一路往上爬：先做 CGI 渲染，就是电影里那种特效镜头；再做批量计算和医学研究；到 2020、2021 年，开始琢磨用 GPU 跑神经网络。

但当时他们不会。于是干了一件很聪明的事：直接买了一批 A100，捐给一个做 Luther AI 开源项目的志愿者团队。因特拉托的原话很妙：

如果是我们捐的算力，就算我们做得不好，他们也不好意思发火。（因特拉托）

这批 GPU 后来成了学费。志愿者团队不断来要更多资源，CoreWeave 由此学会了怎么运行大规模并行计算。更有意思的是，这些志愿者回到各自的日常岗位后，都回去跟老板说：我要那套基础设施，它才是研究人员想用的样子。第一批种子客户就这么来了。

GPU 十六个月就过时？因特拉托：一派胡言

关于 GPU 折旧的争论，市场上一直有空头在讲「十八个月就报废」的故事，迈克尔·伯里也唱空过整个行业。因特拉托的态度毫不含糊：

这个折旧争论就是胡扯，是一批持有空头仓位的人在试图唱低股价。（因特拉托）

他的事实依据很直接：客户跟 CoreWeave 签的都是长约，平均五年。如果硬件十六个月就过时，没人会签五年合同付五年钱。公司自己按六年折旧，认为 GPU 实际寿命超过六年，这也是整个行业的标准做法，唯一的例外是亚马逊。

更能说明问题的是 A100 的二手行情：今年 A100 的价格是涨的。逻辑也不复杂，装机的总容量越大，就会催生越多新公司和新用例，这些后来者挤不进 H100 的队列，转头就把上一代芯片买走了。杰森打了个比方：你用完 iPhone 想换新，觉得谁还要 iPhone 12，但去南美或非洲的店里看看，50 美元一部照样有人买，还剩大把使用寿命。

那到底什么才算过时？因特拉托给了一个可操作的判断标准：当数据中心里的电力能被改去做毛利率更高的用途时，旧硬件才让位。在那之前，从五年长约里滚动退出的设备，现在的售价还比一年前高。

「盒子」：CoreWeave 融到 350 亿美元的秘密

CoreWeave 真正的护城河，可能藏在融资结构里。因特拉托管它叫「盒子」（the box），名字不浪漫，但结构扎实。

流程是这样的：微软这样的客户先来签算力采购合同，合同放进盒子；然后拿合同去找黄仁勋买 GPU，也放进盒子；数据中心的租约放进去。盒子里的现金像瀑布一样流动：微软付款给盒子（注意，付的对象并非 CoreWeave 本身），现金流先付数据中心租金和电费，再付利息和本金，剩下的才回流公司。每笔生意的风险和收益都锁在独立的盒子里，一个盒子出事不会传染给别的盒子。

结果是：CoreWeave 这个没多少人听过的公司，18 个月融了 350 亿美元。而且盒子的经济学非常好，五年合同跑完两年半，本金利息就全付清了。这套结构被反复验证之后，贷款方的信心直接反映在价格上：过去两年，公司的资金成本降了 600 个基点，正在逼近超大规模云厂商的借款利率。这意味着一家小公司靠结构化融资，正在把资本成本拉到能跟巨头正面竞争的位置。

需求、内存瓶颈和一百万 token 的价格

杰森追问：如果英伟达突然说随便下单，全球能释放多少算力？因特拉托的回答绕开了产能，直指风险框架：约束从来都多于 GPU，还有电力、内存、存储、网络和光模块。现在真正的节流阀是内存。

内存是典型的周期性行业，晶圆厂资本开支巨大，供需总是大起大落。这一轮的问题在于两件事撞在一起：AI 需求把内存价格顶上了天，而本来 2023 年就该启动的一轮产能投资没有发生。现在全行业都在追。

需求侧他引用了一个数字，来自 OpenAI 的 CFO 萨拉·弗里尔：GPT-3 时代一百万 token 成本 32 美元出头，现在是 0.09 美元。资本和工程互相点火，成本曲线塌下来，用例自然爆炸。

Perplexity：从「带引用的搜索」到「AI 本身就是电脑」

第二位是 Perplexity 的 CEO 阿拉温德·斯里尼瓦斯。杰森先讲了自己作为重度用户的三段体验：先是任意切换各家模型加侧边栏，后来是 Comet 浏览器能听指令跑任务，最后是刚发布的 Perplexity Computer。斯里尼瓦斯把这条产品演进线归纳成一条主线：准确性。

让 AI 接入互联网是个好主意，这样回答才准确；让 AI 接入浏览器是个好主意，这样执行任务才准确；让 AI 接入整台电脑，它就能干你在电脑上干的一切。（斯里尼瓦斯）

他把 Computer 比作一个乐团：跑在里面的子智能体是乐手，各个模型是乐器。市面上有几百个模型，有的擅长代码，有的擅长写作，有的擅长图像，真正要紧的是最终演奏出来的音乐，也就是 AI 替你完成的工作。

他随后宣布了一个新东西：Perplexity Personal Computer。做法是把服务端的可信执行同步到你本地的一台 Mac Mini 上，涉及私人数据的智能体编排全部跑在本地硬件上，需要时经你许可再调用云端前沿模型。用他的话说，这是「给小白准备的 OpenClaw」：不用管 API 密钥，不用在几十个服务之间分别付费。

企业版一个月 400 美元，而且每一分钱毛利为正

商业上的数字很具体。企业版分两档：Enterprise Pro 每月 40 美元，Enterprise Max 每月 400 美元。Max 档客户用 Computer 已经省下了超过 1 亿美元。企业业务目前的增速超过消费业务，是公司增长最快的板块；消费端月活是几千万量级，团队只有约 400 人。

关于盈利，斯里尼瓦斯给了一个少见的清晰表述：Perplexity 的每一分钱收入毛利都是正的。原因在于收入主要是订阅制，而且因为自己在检索增强、编排和搜索上有积累，不需要把模型的上下文窗口撑爆，token 花得很省。公司整体还未盈利，但方向明确。

当模型开始专业化，「瑞士」策略的价值

杰森的问题很尖锐：面对 OpenAI 融 1000 亿美元、马斯克把数据中心往太空搬、谷歌资源无限的牌桌，一家 400 人的公司怎么活？

斯里尼瓦斯的回答：Perplexity 是瑞士，不押任何一匹马。GPT 赢、Gemini 赢、Claude 赢、开源模型赢，对他都一样。而且他引用了 Anthropic CEO 达里奥的判断：去年上半年大家还在讨论模型会不会被商品化，到年底结论变成了模型在专业化。连编程这一个场景里，Claude Code 和 Codex 的强项都各不相同，他们公司 iOS 工程师爱用 Codex，后端工程师爱用 Claude Code。

模型专业化意味着，那个不押注任何单一模型、只负责编排的指挥家，反而能提供巨头给不了的价值。大厂做不了这件事，做了等于承认自己砸了几百亿美元资本开支还是没造出最好的模型。

这个策略落到产品上有个叫 Model Council 的功能，很多用户可能都没发现：同一个问题同时问多个模型，系统直接标出哪里一致、哪里分歧、哪里有细微差别，省掉你拿肉眼读五份答案的「生物算力」。

转折点是 Opus 4.5：记忆、沙箱与一人公司

斯里尼瓦斯判断能力曲线的拐点出在 Claude Opus 4.5 前后。因为 Claude Code 引入了一个关键理念：一切都在沙箱和控制台里发生，工具就是命令行工具，不需要图形界面。围绕文件、子智能体和命令行组织起来之后，模型对上下文的驾驭完全变了，需要什么放进来，不要就丢出去，超长编排任务突然就跑通了。

他讲了自己团队的使用：董事会备忘录 Computer 一稿写完，给记者的背景简报也是一稿写完，不再需要设计团队和公关团队先做一周。杰森也分享了自己的「哇」时刻：让智能体做日本二十位联系人的人脉图谱，对方反问「你想存到哪里，表格、Notion、CSV，还是我给你写个 CRM 系统」。

斯里尼瓦斯对未来的定义很朴素：AI 一人独角兽公司，现在喊的人多，但真把 GDP 推动十亿美元的还没有。他想做的是让一个本来要去开 Uber 赚外快的人，买台 Mac Mini，装上 Perplexity，让 Computer 跑广告投放、接 Stripe 收款、管客服，真正赚到几十万美元一年。

关于岗位替代，他的立场坦然：多数人本来就不喜欢自己的工作，如果新工具让人能开自己的小生意、有真正的自主感和归属感，那才是值得期待的未来。代价是真实存在的，但机会也是。

Mistral：开源模型加企业定制，生意在欧洲和美国同时做大

第三位是 Mistral 的 CEO 亚瑟·门施。他在 GTC 宣布与 NVIDIA 合作训练下一代前沿开源模型，这是继约十八个月前 Mistral Large 之后双方再次联手。他的逻辑是：先做出最好的开源模型，再把它变成资产，通过定制化服务卖给客户。

很多人以为 Mistral 是一家「法国公司」，门施给了一组纠偏数据：25% 的业务在美国，25% 的研究员也在美国。公司同时布局法国、英国和新加坡。欧洲市场有它的特点，制造业占比远高于美国，而欧洲企业普遍落后一步，正想借 AI 实现跳变。Mistral 的打法是「前置部署工程」：把产品 Forge 和 Studio 直接部署到客户的基础设施上做端到端自动化。

为什么开源模型对企业有独特价值？门施的解释很实在：企业坐拥几十年积累的知识产权和来自工厂、物理系统的信号，把这些数据接进闭源模型并不容易。开源模型可以加参数、做深度改造，还能在任意云、自有硬件甚至边缘设备上运行，成本更可控。ASML 这类重度制造企业就是他们的客户。

数据隔离、合成数据的位置和 OpenClaw 的启示

垂直定制这门生意里，最敏感的问题是数据隔离。门施的解法是把整个训练平台做成可携带的：一整套服务、训练工具、数据处理工具，直接装进客户的基础设施。跟 CIO 谈的时候，这一点最打动人：没有数据回流到 Mistral，一切留在客户那边。

具体落地时，他们会派前向部署工程师和科学家（全是博士）驻场，跟客户的领域专家坐在一起搞清楚比如图像扫描缺陷检测是怎么回事，确定训练数据，最后把能力完整转移过去，确保 Mistral 的团队撤了以后客户自己还能继续训练。数据隔离加知识转移，这两件事的组合是他们的差异化所在。

关于合成数据，门施的判断很克制：可以用它给模型「热身」，用大模型当老师压缩出小模型，前期效率很高，但最终一定要有人类信号，跟专家对话、让专家反馈，这一步的成本省不掉。

对 OpenClaw 引爆的那波热潮，门施的视角是双向的。一方面它对企业远远不够：数据治理、可观测性都不具备。他以客户 HSBC 的 KYC 流程为例，关键关卡必须是确定性的门，每次都走同样的路径，可以向上保证可审计，OpenClaw 给不了这种原语。另一方面，它证明了只要控制平面、沙箱和访问控制设置得当，智能体替员工干活这件事是真的成立的。他还点出一个组织层面的推论：当数据流被智能体重组之后，那个只负责把底层信息搬到顶层的管理岗位，存在的理由正在消失。代价是公司得重新想清楚薪酬数据这类信息的访问边界，这需要一个叫「上下文引擎」的语义层来管住权限。

IREN：用比特币挖矿当融资工具，八年后全部换成 AI 芯片

压轴的是 IREN 的联合 CEO 丹尼尔·罗伯茨。他和兄弟八年前在澳大利亚起步，核心论点是数字世界膨胀迟早撞上物理世界的极限，于是早早拿地、拿许可、申请并网。第一个用例是比特币挖矿，用他们当初对种子投资人的说法：挖矿只是 bootstrap 现金流的手段，更高价值的用例出现之后再一层层叠上去。现在到了兑现的时候：比特币矿机正被 AI 芯片整批替换。

其实 2020 年他们就试过转向，跟戴尔签了备忘录引入客户，回头看太早了，于是退回去继续挖矿攒钱。真正的拐点在两年前，之后需求月月攀升。他们旗舰级的德州站点是 750 兆瓦，四年前在沙漠里建这种规模让整个传统数据中心行业看不懂。

去年年底他们和微软签了一份 97 亿美元的合同。罗伯茨补了一句让杰森愣住的话：这只占他们总产能的 5%。

电力不是瓶颈，时间是：4.5 吉瓦和 45 吉瓦的风光

当全行业都在为电力发愁时，IREN 的答案是从容：他们手里握着 4.5 吉瓦的电力容量，大致相当于整个湾区一年的用电量。所以对 IREN 来说，真正的约束是「算力上线时间」，也就是把技工、地基、水冷、供应链在荒漠里拼装起来的时间。罗伯茨形容这是永久的打地鼠、永远在灭火。

能源结构上有个反常识的事实：IREN 从成立起就是 100% 可再生能源。不列颠哥伦比亚用水电，西德州用风电和光伏。西德州一带有约 45 到 50 吉瓦的风光装机，而把电输送达拉斯和休斯顿负荷中心的输电线只有 12 吉瓦。把数据中心建在多余电力的源头，把电力就地变成数字商品，再以光速输出，这是一门套利生意。而一旦拿到稀缺的并网许可，公用事业公司会兜底全部波动性，保证 24 小时可靠供电。

人的部分同样真实。他们坚持先雇本地人，本地招不到就把招聘半径扩大 20 英里继续找，今年累计社区捐赠达到 100 万美元，用于游乐场和消防站这类项目。选址逻辑也巧：重电网基础设施通常伴随衰落的旧制造业，IREN 利用这些沉没资本，重新雇佣和培训本地劳动力。杰森问技工薪酬是不是 15 万到 30 万美元，罗伯茨说下限方向大致靠谱。当前网站上挂着 129 个职位空缺。

杰文斯悖论：算力越便宜，需求越疯狂

杰森拿黄仁勋主题演讲里 token 成本降 50 倍的说法问：曲线会不会从抛物线回落到温和增长？罗伯茨的判断正好相反，需求会自我强化。他的例子是生成式图像：现在在 ChatGPT 里生图要等好几分钟，像拨号上网的年代，每敲一次提示词都得想清楚。如果把可用算力乘以十（本身就是极艰巨的任务），生图降到五到十秒，人们会生成更多还是更少的图？

答案显然是更多，这就是杰文斯悖论，也是修路诱发车流的老故事。

其他几个判断也都干脆。定制芯片：各家都在推自己的硅并抢数据中心容量，但 NVIDIA 孵化的生态和标准优势巨大，早期大规模扩建最稳的路径还是跟着 NVIDIA 的路线图走。太空数据中心：马斯克长期看对了很多事，但今天看成本和辐射的工程难度极大。核能：必须开始行动，但从政策、资本到大型项目投运要十年以上，现在该做的是启动对话。而关于数据传输这个「数据中心必须挨着大城市」的老教条，IREN 的数据直接证伪了它：西德州沙漠里的站点到达拉斯的骨干机房，往返延迟只有 6 毫秒，而一秒里有一千毫秒。

读完这场访谈，能带走什么

  • 评估 AI 基础设施公司时，别把 GPU 折旧当第一变量。合同期限、融资结构、资金成本的趋势（CoreWeave 两年降 600 个基点）才是决定谁能撑到终局的硬指标。
  • 「模型专业化」是这轮访谈里两位 CEO 共同确认的趋势。做应用层的团队，与其押注单一模型，不如把功夫下在编排层：路由、混合部署、多模型比对，这里有结构性机会。
  • 个人可以认真考虑本地部署的混合方案：一台 Mac Mini 或即将上市的高配桌面工作站，配合服务端编排，既能压低每月订阅账单，也能守住隐私数据。
  • 创业者的团队结构值得重算一遍：招聘、研究、客户支持、备忘录撰写，这些岗位的任务正在被智能体吸收。三人加满配智能体的公司，跟二十人的公司相比，成本结构已经不在一个量级。
  • 关注「时间到算力」这条隐性赛道：电力许可、并网资质、技工培训，这些笨重而慢的环节，恰恰是当下整个 AI 供应链最稀缺的资源。
