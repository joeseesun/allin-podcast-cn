Citadel 创始人肯·格里芬（Ken Griffin）在自家“全球市场未来”年会上说了一句话：AI 几乎可以肯定是个泡沫。他补了一句，泡沫是正常的，任何对经济的彻底改造都和泡沫纠缠在一起。他长期看好 AI，但眼下让他不安的是，企业把大把账单付给 Anthropic 和 OpenAI 之后，开始问同一个问题：生产力到底在哪？

市场的反应很直接。周四，数据中心和资本开支这条线继续被砸：CoreWeave 跌 10%，Meta 财报后跌 6%，AMD 跌 5%，SpaceX 跌 5%。当然，这些票过去两年一直上蹿下跳，整体趋势向上。

查马斯·帕里哈皮蒂亚（Chamath Palihapitiya）接过这个话题，给出的不是情绪，是一张算过账的结构图。

1% 的公司烧掉 90% 的 token，其中八成来自不赚钱的创业公司

查马斯在节目里复述了自己之前的推文：按他的粗略估算，1% 的公司代表了 90% 的 AI 支出，也就是 token 消耗；而这 90% 里，又有 80% 来自不盈利的、VC 支持的创业公司。

他把这个循环拆得很清楚：VC 从养老金、LP、基金会、家族办公室募资，投进一家创业公司；这家公司拿钱去买增长，增长的一部分就是消耗别人的 AI；消耗产生了收入曲线，公司拿着这条曲线去找同一批 VC 再融一轮。钱在同一个池子里转了一圈，估值被 mark up 了一次。

“对 AI 来说，要成为一个可预测的长期盈利驱动力，它必须从创业生态里扩散出去。你不能一边讲着惊人的估值，一边让每一美元里有 75 美分只是创业公司自己来回倒手。”（查马斯·帕里哈皮蒂亚）

他拿云计算早期做对照。AWS 刚推出 EC2 和 S3 的时候，买单的也是创业公司。区别在于，AWS 是从亚马逊零售业务里抽象出来的，而当时的亚马逊零售至少已经在自由现金流层面接近盈亏平衡。今天的情况不一样，一圈亏损的实体在互相倒钱，这个结构必须向外扩散才成立。

为了验证这个估算，查马斯的研究团队找了 Ramp 的首席经济学家阿拉·卡拉齐安（Ara Kharazian）。Ramp 主要给创业公司提供 neo bank 和信用卡服务，手里有大量创业公司的真实支出数据。对方的回复是：查马斯的估算基本正确。Ramp 还同意让 All-In 先发布一张此前没公开过的图表。

这张图看的是 AI 支出前 1% 的公司，钱到底花在哪。蓝色柱子是自购 GPU 算力，玫瑰色柱子是调用前沿闭源大模型的流量，通过 Bedrock 这类渠道。蓝色柱子在往上走，意味着这批最舍得花钱的客户，正在把负载往开源模型和自己的 GPU 上迁。

查马斯还提到一个转折点：Alex Karp 在 CNBC 上谈数据主权之后，大客户的采购模式明显变了。他团队前一天参加美国一家大型银行的 CIO 活动，对方直接说，我们减少了 AWS 和 GCP 的支出，自己从零建了六个完全独立的数据中心。

杰森·卡拉卡尼斯（Jason Calacanis）对这个现象有不同解读。他的基金一年投 100 家公司、评估超过 1 万家，他的观察是：创业公司涌向一项技术，恰恰是强烈的正向信号。因为这群最灵活的人永远在找最便宜、最好、最快的优势。

十五到二十年前是云计算，创业公司省下大量服务器钱；后来是 WeWork，办公成本骤降；再后来是 Facebook 广告，定价错得离谱，创业公司把融来的钱全砸进去买量。现在轮到 AI。大企业永远是最慢的那批采用者，这也是它们一直在收购创业公司的原因。

Nikesh Arora：企业最终要的是能审问思维链的模型

Palo Alto Networks CEO 尼克什·阿罗拉（Nikesh Arora）上周刚在纳帕办了一场 CIO 活动，他先回应了开源与闭源之争。

Palo Alto 自己偏好开源、开放权重的模型，理由有三个：可以改权重、可以自己训练，再加上一条大多数人不太谈的，可以审问模型的思维链（chain of thought）。

“所有企业最终都需要可解释性、可验证性和可审计性。我没法跑去跟老板说，我不知道发生了什么，反正 IT 部门装了个 AI 模型，是它干的。这在金融和医疗的监管面前根本过不了关。”（尼克什·阿罗拉）

现实约束也很硬。除了 hyperscaler，现在几乎找不到一个全球覆盖、高可用、有韧性的推理服务商。创业公司可以去某个数据中心租 10 兆瓦，宕机几小时也无所谓，反正自己是创业公司。一家要提供 99.9% 可用性服务的企业做不到这一点。

查马斯追问：有没有一种可能，Palo Alto 跑去跟 hyperscaler 说，你帮我跑，但我要裸金属、要完全气隙隔离，设施是你的，我只租用？或者像那家 GSIB 银行一样，干脆自己建？

尼克什的回答很现实。他六七年前刚到 Palo Alto 时，把公司所有自建数据中心都关了，理由是自己跑不出 hyperscaler 那种规模、速度和可靠性。现在算力变得极度稀缺，他反而成了一个“条款接受者，而不是条款制定者”。

“你去找黄仁勋，他 2028 年之前给不了你芯片。你去找土地、电力、厂房，也一样。所以‘我自己建数据中心’这句话，某种程度上是空头威胁，很难真的建成。”（尼克什·阿罗拉）

他判断最终的形态在中间：企业会拿到裸金属，可能来自 hyperscaler 或 hyperscaler 的近亲，也可能是有人把全球各地的算力缝起来满足需求。随着时间推移，hyperscaler 会开始提供裸金属让客户跑开源模型，这已经在部分发生。利润池正在从英伟达和内存行业，往手握大量算力的 hyperscaler 转移。到最后，竞争的关键落在算力的可获得性上，芯片不再是分水岭。

他还补了一句对“企业扩散太慢”这个说法的反驳：就算今天全世界每家公司都说我准备好了、全力上 AI，全球的算力也不够用。需求是吃不饱的。

PHP 漏洞：一个 9.2 分的洞，和一场提前泄露的补丁

节目录制的这一周，正好撞上了一场网络安全事件。

PHP 这门开源语言支撑着大约 70% 的网站，WordPress、维基百科都在其中。今年 8 月，安全研究人员借助 AI 发现了两个严重漏洞，代号“PHP to Shell”，PHP 安全团队给出的严重性评分是 9.2 分（满分 10），对安全团队来说基本等于 DEFCON 1。

按照标准流程，开发者和公司一起修，计划在 10 月 22 日、也就是节目录制当天，统一发布一个大补丁。但在发布前几天，漏洞信息泄露了，泄露源目前不清楚，这会是事后复盘的一部分。PHP 把发布时间提前了一天，改到 10 月 21 日周三。

周三，事情炸开。AWS 报告黑客活动激增，Cloudflare 的 CEO 说他们看到了数百万次攻击尝试。一批预防性关停开始出现：欧洲多国政府（法国、德国、荷兰、丹麦、芬兰等）开始下线网站，维基百科关掉了部分系统去打补丁，美国 NSA 和 FBI 发布警告。恐慌蔓延到普通人层面，开始有人担心比特币、自己的网站、银行账户会不会被黑。

杰森问尼克什：你什么时候知道的？这是急性事件，还是未来一年的预演？会不会每十天就来一次？

“十天太长了。这类事情会来得比每十天一次快得多。”（尼克什·阿罗拉）

他接着讲了一个 CIO 当天的真实处境：这家公司有一堆网站，一部分跑在新版本上，能打补丁；一部分跑在老版本上，打不了，只能先下线、重建、再上线。而这些年他们一直没处理老版本，因为“不重要”。技术债从来不是抽象概念，它在某一天会变成一张必须当天付清的账单。

解决办法有两条。一条是进代码里打补丁，把 PHP 给的修复应用上去。另一条是在边界防御产品上打“虚拟补丁”，Palo Alto 有，Cloudflare 有，其他防火墙也有，攻击者流量先撞到 CDN，撞到边界，根本到不了源站。

查马斯问了一个更关键的问题：闭源模型在这件事里帮上忙了吗？是它们帮忙找到的这些 CVE 吗？

尼克什确认，OpenAI、Anthropic，大概率还有谷歌，现在的模型足够强，只要给足算力和持续性，它们就能找出漏洞，甚至能把多个漏洞串成一条攻击路径。PHP 这个问题几年前就被识别出来了，但当时没人认为能解决，因为它需要的协调量太大。扔足够多的算力进去，它持续啃，最后啃开了。

而一旦漏洞被公开，逆向工程就开始了。黑客看补丁在做什么，反推回去，没打补丁的系统就成了靶子。

Agent 登进你的银行账户，出事算谁的

大卫·弗里德伯格（David Friedberg）把话题引向另一条同时爆发的支线：银行发现大量“未授权访问”。他判断可能有两种来源。一种是 PHP 漏洞导致网站可被攻破、凭证被拿走；另一种是个人 Agent 的问题，Agent 拿着你的账号密码登录银行，银行分不清这是你本人还是你的 Agent。

传统上银行开放账户数据走的是 API，通过 Plaid 这类经过验证的中间层，有明确的法律授权路径。现在 Agent 直接从前端网页登录，绕过了这套体系。

尼克什说，这背后是责任归属问题，而且银行已经在用最省事的方式自保。

“你给了 Agent 你的凭证，它住在你的浏览器里、你的笔记本上，它会拿到无数个凭证。最大的问题是：谁承担 liability，谁负责。所以你会看到银行直接说，我不允许你用 Agent 跟我交互，先把免责声明喊在前面。”（尼克什·阿罗拉）

他还提到一个成本逻辑：银行对小额信用卡争议的态度一直是“直接赔给你”，因为客服电话的成本比赔的钱还高。如果大量 Agent 交易开始产生争议，用户打电话来要解释，这个成本结构就崩了。

CAPTCHA 这道防线也已经不太管用。AI 识别 CAPTCHA 的能力很强，有些场景下干脆弹出一个虚拟浏览器，让人接手过了验证再交还给 Agent。

杰森问了一个更阴谋论的可能：这会不会是银行故意放出的 FUD，好把 Agent 挡在门外？因为一旦 Agent 能自由进出，它就能替用户挑利率更好、服务更便宜的银行，银行的护城河就没了。

尼克什的回答是：这给了银行太多信任。他们现在真正的麻烦在责任归属，跟竞争没关系。

查马斯抛出一个具体场景：我用一个 Agent 服务，把银行凭证给了它，5 万美元不见了，可能是提示注入，可能是 Agent 自己跑偏转了账，谁负责？应该谁负责？

弗里德伯格的答案基于服务条款：银行的服务条款里已经写明不能用 Agent 通过网站访问账户。如果 Agent 没有识别并阻止这个行为，那是 Agent 提供方的软件责任；除非它弹窗提示你“这违反服务条款，你要不要覆盖我的阻止”，那时责任才转移给你。

杰森补充了一个正在发生的判例：亚马逊已经封了这类购物 Agent。Grok 现在的说法变成“我可以帮你加购物车、选地址、选卡，但买按钮我不按”。规则正在实时被裁定出来。

尼克什的立场更直接：

“Agent 这个词里有 agency（代理权）。是谁给了 Agent 代理权？是你，还是 Facebook？如果是你给的，责任就在你。但有一个例外，就是 Agent 跑偏了。产品没有按它宣称的方式工作，那就是产品责任，是造它的人的问题。”（尼克什·阿罗拉）

查马斯同意这个划分，并给出一个务实理由：只有让责任落在用户身上，这套东西才能规模化。否则一出事，美国银行指向 Facebook，Facebook 指向用户，链条走不动。

白帽的算力优势今天还不成立，技术债才是根

杰森抛出三个流行理论，让尼克什逐一判断。

第一个：这最终会变成算力之争，白帽手里的算力最多，所以能压过黑帽，朝鲜、俄罗斯、中国的黑客拼不过。尼克什的回答是：今天不成立。原因是底层系统没有被架构和编排成可以投放“防御性蜂群”的样子。如果成立，理论上你可以派一堆 Agent 去给 5000 个网站打 PHP 补丁，但现实是 IT 人员还在一个个手工编目，因为这些资产从来没被聚合成一张图。

第二个：持续性算力加上主动排查，最终会解决问题。尼克什的回答是：成立，但这会是一场持续的猫鼠游戏。现在的做法是，几乎每一家大企业都在用 Mythos 这类模型攻击自己的防御，找洞、打补丁。下一个模型更强，会找到更多进入方式。

他给了一个思路上的转向：假设你一定会被攻破。问题就从“哪个漏洞会让人进来”，变成“我多快能发现、多快能把他赶出去”。要做到这一点，前提是把所有信号、所有数据聚合起来，用白帽算力去识别异常行为。

第三个：前沿模型在“守门”，把最强的攻防能力攥在手里，反而限制了白帽。尼克什认为这个说法给了模型公司太多信任。他们大多是研究人员出身，自己也在问“这东西太强了，我该怎么用、怎么发布、怎么打包”。而且他们全都受算力约束，在给所有人限速，包括他自己。

“他们并没有制造问题，他们在对付一个极其强大的东西。他们想要的是变现。他们需要钱，因为要还给黄仁勋。”（尼克什·阿罗拉）

杰森提到自己孵化的公司 Obliteration AI，做的是没有护栏、没有约束的模型，交给红队和白帽去做渗透测试，客户名单和 Palo Alto 高度重合。查马斯的反应很强烈，说这是他目前认为最被低估的风险向量，比对齐问题更值得普通人理解。尼克什则把它称为 AI 的暗面：

“你依赖的是最弱的那一环。如果有一家公司把没有护栏、没有治理的原始能力交出去，等于把核弹交给任何付得起钱的人。一边我们在白宫谈全球条约、谈对齐、谈发布前测试，另一边你说这里有套 DIY 阿司匹林工具包，自己配药吧，玩得开心。”（尼克什·阿罗拉）

关于技术债为什么会积累，查马斯补了三个机制：没人愿意干维护，大家都想做下一个新东西；软件装进客户自己的 VPC 之后会产生版本漂移，供应商要同时维护十几个版本；技术变化太快，沉没成本又让人没法推倒重来。尼克什补了第四个：CIO 的激励结构。他们的考核是压低成本、保持可用，而每次升级都意味着宕机风险和用户投诉，还要花钱。所以“不动”永远是最安全的选择。

杰森把它类比成情报机构：没有恐袭的时候，大家觉得你花太多钱；出了事，大家问你怎么没防住。这套激励错配，在未来一年会以一连串“网络世界的 9·11”的形式被强行纠正。

尼克什还提到一个数字：企业 IT 预算里，安全通常占 4% 到 10%。10% 是金融服务业和联邦政府的水平，4% 到 5% 是云公司，因为基础设施安全由 hyperscaler 兜了。这个比例会往上走，因为 AI 的安全框架根本还没建起来。

“飞机刚发明的时候，莱特兄弟在那飞，没人说我们去建个 TSA。现在到时候了，因为坏事一定会发生。”（尼克什·阿罗拉）

节目里还提到当天早上的一条研究：把一段 Muse 的对话转发给别人，可以从里面提取出私人信息。团队又得回去改。

至于伯尼·桑德斯在推特上喊“停止 AI”，尼克什的回应是：听起来是个好主意，你先来，我跟着。他接着说了一句更值得琢磨的话：人类历史上第一次，我们如此集中地凝视技术的暗面。

“我们只听到这项技术做的所有坏事。我的天，我中了提示注入。我的更糟，我的六个月前就被越狱了。这些叙事一个比一个糟，简直是叙事上的逐底竞争。”（尼克什·阿罗拉）

杰森的解释更接地气：民粹议题。如果实验室的人亲口告诉你一半白领工作要消失、司机要消失、10% 的人会死，那对一个右翼的美国优先民粹者，或者一个左翼自由派，这都是绝佳的动员材料。

法国：50 万人上街，10 年期国债破 5%

两周前节目聊过法国，这次情况更糟。超过 50 万人参与抗议，蔓延到意大利、西班牙、阿尔巴尼亚。周末出现了几十年来最严重的骚乱。数字很硬：超过 3000 家企业受损，损失数亿，1000 多名警察受伤，2500 人被捕，其中 70% 是成年男性。

起因是高中抗议，学校年久失修、经费不足。现在变成了全面的社会失序和抢劫。多座历史政府建筑被烧，包括距巴黎以南 250 英里、有 143 年历史的 Le Mages 市政厅。法国终于开始实施宵禁。

《纽约时报》的表述是：法国政府指责极左激进分子和机会主义抢劫者制造暴力。特朗普和万斯把这件事定性为第三世界的移民和福利国家问题。法国司法部长的说法更微妙：抢劫者里有移民背景的人、有外国人，但也有完全融入的法国人。

市场已经在定价。法国 10 年期国债收益率本周突破 5%，2002 年以来最高。同一时间美国 10 年期一个月来首次跌破 5%，《华尔街日报》的解释是资金从欧洲债市逃向美国。Polymarket 给出的两个概率：法国年底前宣布紧急状态 18%；穆迪或标普在 10 月 31 日前下调法国评级 91%。

查马斯的措辞在整期节目里最重。他说这些人是绝对的罪犯、是恐怖分子，应该全部逮捕。他认为这暴露了所有这些政府宣扬的“同理心”的终点，那是一种伪装起来的、鼓励城市混乱的东西。他提到马克龙上电视时还在谈“这些人一定在受苦”，而画面里的人不像在受苦，像在制造混乱和国内恐怖主义。

“法国会陷入极其困难的经济处境。它已经提出 500 亿欧元的紧缩，这个数字还得往上走。我想不通，在一个紧缩方案里，你怎么还有钱去投教育来安抚这些人，如果那真的是他们在抗议的东西。政府处在必输的局面，我认为他们会输掉接下来的总统选举，法国官僚体系和经济会经历一次非常复杂的重置。”（查马斯·帕里哈皮蒂亚）

弗里德伯格把这件事放进一个更长的框架。他先区分了一下：美国此前的 BLM 骚乱、1 月 6 日事件，都有非常具体的政治或社会政治触发点，而法国这次的不满来源非常分散。街头采访里，有人谈学校，有人谈自由巴勒斯坦，有人谈医疗、就业、支持不足。共同点是：要求政府为民众做得更多。

然后他放了一张图。这张图比较的是法国公共支出占 GDP 的比例，和主要共产主义国家在峰值时期的公共支出占 GDP 比例：1989 年的苏联、罗马尼亚、查韦斯治下的委内瑞拉、共产主义中国。

“我们总觉得问题出在马克龙或者某个人身上。但事实是，政府花得越多，民众的处境越差，不是越好。然后民众上街，说政府花得不够，政府要做得更多。”（大卫·弗里德伯格）

他接着给了美国的数字：联邦政府支出 7.4 万亿美元，州和地方政府支出 4.6 万亿，加起来 12 万亿，对 33 万亿的 GDP，美国公共支出占 GDP 大约 36%。法国的债务对 GDP 是 120%，美国也差不多。法国的国家级财政赤字占 GDP 5.4%，美国 6.2%。区别在增长：法国 0.5%，美国 2.3%。

他的判断是：法国的经济指标和美国高度对齐，只是法国先撑不住。法国是西方的风向标。

查马斯追问：那你具体认为该做什么？弗里德伯格给出四条：砍支出、砍赤字占 GDP 比、砍项目。具体到四个领域：

  • 教育：逐步取消联邦学生贷款项目，同时处理存量学生债务，让它可以通过破产程序解除。这会倒逼高校按市场重新定价，过程大约需要十年。
  • 住房：减少联邦住房贷款的承销规模。这部分信贷长期在推高房价，让中产阶级账面资产好看，代价是年轻人买不起房。
  • 退休：把固定收益型退休计划（包括社会保障信托基金）定为非法，用十年时间逐步转为固定缴费型。已累积的权益按每年 10% 转入个人账户，个人可以按年龄选择 40/60 或 80% 债券的配置。他拿澳大利亚的 superannuation 和挪威做例子。
  • 医疗：最难的一块。核心是把保险市场推给雇主，让雇主进入市场议价，从而压低价格。障碍是 HIPAA 和住房监管。

查马斯立刻提出了那个尖锐的反问：法国和意大利理论上已经解决了四件事里的两件，教育基本免费，医疗基本免费。学生债是美国特有的问题，在这两个国家不存在。退休体系的问题和美国的逻辑类似。两件解决了，一件压根不存在，他们还在烧。那说明问题不在清单上。

杰森接了这个话。他说最早的抗议是学生，比较温和，扔几个瓶子，没有抢劫。抢劫是后来由来自北非的非法移民，以及大量未被允许融入社会的穆斯林移民群体做的，其中有些已经是第二代、第三代巴黎人。他认为如果这批人不在，这就只是一场关于教室好一点、师生比低一点的普通抗议。

弗里德伯格的回应是：我也不确定那两件真的“解决了”。看医生的等待时间是几周，教育质量很差，一个班 60 个孩子，这正是学生在抱怨的东西。他放了一段视频：有人在街头采访，问为什么骚乱者要针对华人商店，回答是“中国人在法国变得太富了，这不公平，他们现在穿好衣服、开大车”。

“这就是庞大的社会主义、庞大的政府带给所有人的东西：如果任何人看起来比我们共同承受的苦难过得好，那他们一定是问题，他们是坏人。这种情绪和自由巴勒斯坦运动、和反父权制，根子上是同一个东西。他们没意识到，自己之所以有这种感觉，是因为政府已经试图做得太多，而且做不好，因为政府是提供服务最糟糕的地方。”（大卫·弗里德伯格）

杰森补了现场细节：抢劫者专门针对华人和犹太人店铺，刻意避开穆斯林商铺。他提到洛杉矶骚乱时的“屋顶韩国人”，韩国店主端着枪站在自己店顶上守住了产业。他说，感谢第二修正案，他不认为美国会出现这种持续性的骚乱。看到那些把一生积蓄投进一家小店、被打、看着店被烧掉的店主，他的反应是：我希望这些人有枪。

查马斯把这一幕类比到 1938 年：

“听到那个年轻人谈为什么要针对中国人，很奇怪地让人想起一场自下而上的、组织得很差的水晶之夜。1938 年是犹太人的商铺和犹太会堂被砸，那是国家主导的，但动机里也有嫉妒。现在你看到的是有人在烧、在抢，其中至少有一小部分人，是在针对一个他们嫉妒的群体。”（查马斯·帕里哈皮蒂亚）

他把对比拉到两个移民群体上：一边是喊着“这不公平”（c'est pas juste）、像个任性的孩子的人；一边是那个在餐馆打了 34 年工、攒够钱才开了自己店的中国移民。“让我上场，我准备好了。”两边都是移民，这个反差是最刺眼的地方。

杰森讲了自己家的经历：父母开餐馆，妈妈是护士不是糕点师，为了省钱自己做甜点；他和兄弟从六七岁起就在店里摆桌、擦银器，十岁进厨房干活，一家人还是周周紧巴巴。他说，你要是来烧我父亲的店，我父亲是带着枪的。

债券义警、8% 的收益率，和一个没人能想出来的终局

查马斯给出了他认为唯一的现实路径：债券义警。

“债券义警可以打断法国政府的脊梁。他们可以通过让法国债务变得无法融资来做到这一点，把长端利率推得足够高，让它融不到钱，从而在法国国内触发一次经济重置。我觉得需要把法国国债推到 8%，直接打断它。”（查马斯·帕里哈皮蒂亚）

他同时承认这条路的副作用：历史上每一次这样的重置，都会有人在这个过程中积累更多权力，然后盘算自己在接下来五年、十年里怎么用这份权力。真正正确的重置，应该去动养老金体系、去规定班级师生比、去规定医院等待时间、去动建筑许可和租金调整后的通胀。现实不会那样走，现实会变成谁在台上、谁把责任推给别人、谁在重置之后拿到未来十年的权力。因为重置的过程里，人们会把自己的权利一项项交出去。

那还剩什么？他自问自答：只剩那个没人愿意相信的万灵药，AI 带来的丰裕。可这话从一个硅谷投资人嘴里说出来，法国街头的普通人只会觉得，一群寡头在讲什么鬼话。

“不可阻挡的力撞上不可移动的物。我在脑子里模拟不出一个结果。我看不到一个合理的终局，所以我完全困惑，完全无解。”（查马斯·帕里哈皮蒂亚）

弗里德伯格给出两条可能的分岔：一种是社会层面的崩溃，骚乱、凶杀，像某些国家经历过的那样；另一种是经济层面的崩溃，像阿根廷、巴西，更近的希腊，政府太大、还不起债，被迫重组。后一条路上依然会有大规模抗议、净值大幅缩水、通胀吞掉资产价值，但是一次经济重置，不是社会重置。

他对美国的判断是：美国不可能长期维持一个比法国更高的赤字占 GDP 比、和法国一样的债务占 GDP 比，而只靠略高一点的增长撑着。某种程度的重置是需要的，问题是要社会重置，还是左右两派都戴上安全帽下矿井，认真把 7.5 万亿砍到 4 万亿，同时不把经济搞死。

他还是回到那张图：法国税收占 GDP 46%，排在世界前列。高税收加上低增长，结果就是一个没收性的政府占据了经济的绝大部分，产出却是糟糕的。

“问题摆在美国面前：你想在这两张图上往上走，还是往下走？往上走，所有人的生活质量都下降，向上流动的能力被摧毁。往下走，每个人的机会变多，但你必须靠自己，必须有更多 agency。这就是这个国家立国的北极星，我们该谈的是怎么回去。”（大卫·弗里德伯格）

杰森在这里提出了整期节目里最有价值的一个反驳。他说，大多数美国人，尤其是年轻人，并不相信这套。看那张图，美国前面是澳大利亚、阿根廷、韩国、日本、巴西、加拿大、英国、德国、意大利、法国，大多数抱怨现状的美国人，其实是想去那些国家的，想要那里的医保，想要那里负担得起的大学。

查马斯不同意，说他去过名单上的每一个国家，还在其中一个做过公民，他不会选其中任何一个。弗里德伯格补了数据：巴西的青年失业率大约 15% 到 16%，正在往 20% 走，美国还在 10% 以下。如果真想去，买张机票就行了。

杰森把论点收窄了一步：他说人们想搬过去的意愿未必有那么强，真正想要的是那些国家承诺的东西，而且愿意为此多交税。

弗里德伯格的回击是：那些国家交付的不只是“看病不要钱”，还有工作和向上流动的可能性。而要同时拿到这些，最好的系统是小政府，因为政府越大，你实际拿到的那块饼越小。

杰森承认自己在这个点上和对方立场接近，但坚持那张图不是好证据。他的原话大意是：大多数美国人并不创业，他们想要更多的服务，他们认为那些国家就在我们上面一点点，因此不介意多等几个小时、几个月，因为现在他们要么没有医保，要么被医保搞破产。这就是美国医疗系统功能失调的程度。

特朗普的第二任期，缺的是一个替下半部分人说话的人

杰森把话题拉回美国政治。他这周发了条推，说特朗普想救第二任期，得把谈住房的力气，提到和谈数据中心一样的量级。再把最低工资往上提一提，联邦最低工资只影响 1000 万到 1500 万人，是个姿态问题。

“他不谈最低工资，不谈住房，不谈通胀，只说一切都会好的，我们正处在黄金时代。但他非常乐意谈我们的议题：数据中心、加密。这个国家的信息传递严重跑偏了。除非办公室里那个人愿意替下半部分美国人说话，一半一半，我们谈大科技、谈减税，但我们也谈提高最低工资，也谈建更多可负担住房，而不只是更多数据中心。”（杰森·卡拉卡尼斯）

查马斯替特朗普辩护：如果你读他发的东西，他把这些点是连起来的。他清楚 AI 建设占了 GDP 里不成比例的一块，而且不只是拉动七家公司的股价，还大幅拉高了中产阶级和熟练工人的工资。他一直在告诉企业，要建数据中心就把电费降下来、建在电表后面、投资当地社区。美国经济现在完全绑在 AI 这笔交易上，这一点没有争议。

杰森同意特朗普在经济上的操作比他这辈子见过的任何一位总统都好，但强调公众不这么看，这就是他支持率创历史新低的原因。这是沟通问题。

然后就有了那段关于新闻秘书的对话。查马斯先夸了卡罗琳·莱维特（Karoline Leavitt），说她设定了一个极高的标准，那么年轻，能力强得惊人，接她班几乎是不可能的工作。接着说杰森：

“你是一条非常顽强的斗牛犬。我觉得你要是认识了总统，你会跟他成为好朋友，你会是个了不起的新闻秘书。问题在于，你有一些愚蠢的想法。只要你能忍住不去代表那些愚蠢的想法，你会非常有效。”（查马斯·帕里哈皮蒂亚）

“愚蠢的想法”指的是最低工资。

最低工资之争：一次关于市场边界的老辩论

杰森的方案很温和：联邦最低工资几十年没动，每年加 1 美元，七年加到 15 美元，到 2032 年完成。只影响不到 1500 万人，一半的州有自己的更高标准，联邦这一档对它们不起作用。他的论据是，钱会重新流回同一批公司，形成货币流通速度，澳大利亚、新西兰、北欧都验证过。

弗里德伯格拿加州 AB 1228 举例：2024 年把快餐业最低工资提到 20 美元，结果加州少了 1.8 万个快餐岗位。逻辑是，快餐卖的是便宜，消费者只愿意为汉堡付 4 美元，不愿意付 8 美元。当劳动力成本被强行推到市场支付意愿之上，就没有人能来支付这些工资，结果是消费者失去了附近的快餐店，员工失去了原本自愿接受的岗位。

“如果买家和卖家自己能谈拢，市场会找到一个舒服的中间点。政府一介入，市场就炸了，供给被破坏，需求被破坏，人丢了工作。一次一次都是这样。”（大卫·弗里德伯格）

杰森反驳两点。第一，他并没有主张一步提到 20 美元，把加州最激进的做法跟他这个温和方案混为一谈，属于偷换。第二，那些店每个餐只涨了 25 美分，被自动化替代的主要是收银员这类本来就要消失的岗位，加州整体失业率并没有恶化，那些人找到了其他更有产出的工作。他反过来用弗里德伯格自己的常用论点：你不是一直说人会找到更有产出的工作吗，这里不能两套标准。

弗里德伯格不让步：只要你去替市场判断什么价格是对的，你就会破坏市场。那个 1 美元也会在某个环节把某批买家推出支付意愿的边界，一部分卖家退出，这门生意就没了。他给的替代方案在税收端：把最低收入段的税率降到零，配合税收抵免，让人把钱留在自己口袋里，而不是强行干预价格。

两人最后谁也没说服谁。杰森收尾时说了一句：我们已经有最低工资了，所以真正在争的是它应该是多少。

给读者的行动清单

  • 看 AI 收入质量，不只看增速。查马斯那张图给出的检验方法是：这家公司的收入里，有多少来自同样靠 VC 输血的同行。如果一个客户群的付费能力建立在下一轮融资上，它的收入就不该被当成终局收入来估值。
  • 企业选模型时，把可解释性当成硬指标。尼克什的判断很实在：金融、医疗这类受监管行业，最终一定会被要求能审问模型的思维链。现在就评估开源、开放权重方案，比事后返工便宜。
  • 把技术债当成一张有到期日的账单。PHP 这件事的教训在于，那些一直没升级的系统，某一天会要求你当天全部下线重建。趁没有事件的时候做资产清点，成本最低。
  • 给 Agent 授权前，先想清楚责任落在谁身上。服务条款里写着不能用 Agent 访问的，就不要用；如果产品方提供了“覆盖阻止”的选项，按下那个按钮的人是你，责任也就转移到了你身上。
  • 把法国当成一个财政样本，别只当社会新闻看。美国的赤字占 GDP 比法国还高，债务比持平，只是增长快一点。看法国 10 年期国债收益率的走势，比看骚乱视频更有信息量。
  • 做投资判断时，盯住债券市场而不是议会。查马斯给出的观察点是长端利率：真正能迫使一个国家改革的力量，在于让它借不到钱。选举做不到这件事。
  • 判断政策时，问一句“谁在付钱”。最低工资、免费教育、免费医疗，这些争论绕到最后都是同一个问题：成本落在谁身上，收益落到谁手上。想清楚这一层，很多看起来对立的立场就能被拆开。
