Anthropic 训练出了一个新模型，它在 OpenBSD 里挖出一个潜伏了 27 年的漏洞，OpenBSD 被用在防火墙和关键基础设施里。它还在 FFmpeg 里找到一个存活了 16 年的 bug，这个 bug 躲过了 500 万次自动扫描。Linux 内核里的问题也被它翻了出来。然后 Anthropic 决定：这个模型不发布。

公司给出的理由是它太危险。模型能自主发现成千上万个漏洞，覆盖每一个主流操作系统和浏览器，包括一些被安全审计漏掉几十年的老漏洞。为配合这个决定，他们还发了一支氛围拉满的宣传片，达里奥·阿莫代伊（Dario Amodei）亲自出镜。

作为擅长代码的副作用，它也很擅长网络攻击。（达里奥·阿莫代伊）
这个我们正在试验的模型，在识别 bug 上已经和专业人类差不多。它能发现更多漏洞，也能更快修掉它们。（Anthropic 工程师）

真正让人后背发凉的是后半段：模型能把漏洞串起来。两个单独看都没什么用的漏洞，模型可以把三到五个连成一条链，制造出极其精密的攻击。

Mythos 到底是安全底线，还是又一次营销动作

布拉德·格斯特纳（Brad Gerstner）是 Anthropic 和 OpenAI 两家公司的投资人，他在这件事上的态度很明确：这几家公司值得大加赞赏。

他的逻辑是，公司本可以直接把 Mythos 放出去，把互联网的一部分基础设施砸烂。硅谷的口头禅是「快速行动，打破东西」，放在这里就等于抢先发布，把竞争对手甩得更远。但 Anthropic 跑了自家的漏洞测试，看到它会让人发动攻击、暴露浏览器历史、暴露信用卡，于是选择了另一条路。

这条路叫 Project Glasswing，一个由 AI 驱动的网络安全联盟。苹果、微软、谷歌、亚马逊、摩根大通等 40 家最重要的公司都进来了。目标简单到一句话能说完：花 100 天，用最先进的 AI，在黑客动手之前，找到并修复、加固这些软件漏洞。

格斯特纳把它定义为一个门槛。Mythos 和 OpenAI 即将发布的 Spud，是他所说的 AGI 模型的开端。这类模型的能力是阶跃式的，聪明到不能一做完就立刻公开发布。他这个观点里有一层隐含批评：并不是每个模型做完都得马上 GA，沙盒化、组建防御联盟，是可以成立的。他还专门强调，Anthropic 和政府有沟通，但协调主要发生在行业内部，没等自上而下的监管。

大卫·萨克斯（David Sacks）的态度要拧巴得多。他先给了这家公司一个标签。

Anthropic 证明了自己非常擅长两件事。一是产品发布，二是吓人。（大卫·萨克斯）

他翻出了一年前那桩丑闻：Anthropic 曾发布一份研究，说新模型会勒索用户。萨克斯的说法是，那份研究对模型提示了 200 多次才逼出想要的结果，结论是反向工程出来的。他的反驳证据是时间。一年过去了，市面上已经有一批能力相当的开源模型，现实里却没见过一起模型勒索事件。如果那份研究反映的是模型的真实倾向，这一年里应该满大街都是案例。

但这一次，萨克斯站在了「这可能是真的」那一边。他的推理链条是：编程模型越强，找 bug 的能力就越强，串起多个漏洞制造攻击的能力也越强。所以未来大约六个月会是一段一次性的追赶期，AI 驱动的网络安全会集中发现过去二十年潜伏在各类系统里的问题。

他给出的窗口期数字是六个月。参照物是中国的开源模型 Kimi K2，大概落后六个月。在这个窗口里，拥有大型代码库的公司能提前拿到这类能力，在能力普及之前把自己系统里的漏洞补掉。他点名说，每一家公司、每一个 IT 部门、每一个管代码库的 CSO 都该认真对待，用接下来几个月去检测和打补丁。

只要每个人都做好自己的事，反应正确，我不认为这会是 Anthropic 描绘的那种末日场景。但恐惧本身可能是一件好事，它能驱动正确的行为。（大卫·萨克斯）

他预判这件事会以 AI 攻防军备竞赛收场，然后进入一个更正常的时期。

「关掉互联网五年」与 2019 年那次 GPT-2

查马斯·帕里哈皮蒂亚（Chamath Palihapitiya）的判词只有一句：大部分是作秀。

他搬出的旧案是 2019 年 2 月。那时达里奥还在 OpenAI，他们对 GPT-2 做过同样的事。那是个 15 亿参数的模型，放在 2026 年听起来像放了个屁，但在当时被描述成末日开局，说会释放出海量垃圾信息和假消息。结果呢，OpenAI 用六到九个月做了一套分阶段发布，先放出小参数版本，最后才放大的。等一切结束，是个彻头彻尾的空炮。

他接着给出了一个二选一：如果 Mythos 真能做到它宣称的事，那么有两个推论同时成立。第一，一个足够老练的黑客今天用 Opus 就能做到这些。第二，如果这些漏洞真的这么容易找，那么无论你用的是 Opus 还是 Mythos，现实里唯一能彻底修补它们的办法，是把互联网关停大约五年。

他顺带嘲讽了一轮：「当你看到一家市值几万亿美元的系统重要性银行也在名单里，这里就有点剧场感。你觉得两个月能干什么？真觉得这些漏洞两个月就能全修好？那给它六个月、九个月。但现实是资本主义会往前走，融资需求会往前走，这些公司建立用户采用率的需求也会往前走，这些都会盖过这件事。」

他对萨克斯的判断表示认同，说这家公司找到了一块非常聪明的市场推广肌肉，能同时激活超高关注度和超高使用率。然后他把赞美给到底：

Anthropic 现在火力全开。这就像库里在场上无所不能，从每个位置扔三分。（查马斯·帕里哈皮蒂亚）

他唯一挑的毛病是名单选错了对象。如果真觉得这事到了末日级别，那至少得把能源公司、控制核反应堆的公司、每天用几百架相当于人造导弹的飞机运送几十万人的航空公司拉进来。这些一个都没在名单上。杰森·卡拉卡尼斯（Jason Calacanis）反驳说，这些可能正是名单上那 40 家公司的客户。

杰森自己的立场最激烈。他说这就是 code red、DEFCON 级别的时刻，必须认真到骨子里，这些公司应该和 CIA 协调，既是防御机会也是进攻机会。他也顺势邀请达里奥上节目，并抱怨自己邀请了三次、拿到了电话号码，对方一直没回。

OpenClaw 被绊倒，以及编程领域的「主导份额」之争

萨克斯把话题拉到了另一条线上。OpenClaw 的创始人彼得·斯坦伯格（Peter Steinberg）公开说，Anthropic 切断了他对 Claude 的访问。

杰森解释了机制。订阅制本质上是把用量在大量用户之间平均摊：九成用户用不完自己付的额度，一成用户用得远超。OpenClaw 变成现象级产品后，那批拿 200 美元月费的人，实际消耗的是两千到两万美元的 token。Anthropic 的回应是：你不能再用订阅接 OpenClaw，得转去 API，按量付费。

杰森把时间线摆了出来：掐断访问之后不到十天，Anthropic 就发布了自己的 agent 技术，官方说法是一个更安全、更好的 OpenClaw。

萨克斯追问了一句更尖锐的：Anthropic 自家的 agent harness，是不是还在那个打包的固定费率里？如果是，第三方走计量费率、自家走固定费率，那就是 bundling 问题。杰森顺着往下说，还可以从 token dumping 或价格倾销的角度看。萨克斯把前提钉死：这要成立，前提是 Anthropic 在编程领域拥有主导市场份额，而他认为大多数人会同意这一点。

格斯特纳从投资人的角度做了辩护。他先摆出一个事实：OpenClaw 依然可以通过 Claude API 使用。每家公司都有权为自己的产品定价，之前的状况相当于用一毛钱卖一块钱的额度，现在只是把定价拉回理性。至于企业为什么倾向用 Anthropic 自家的版本，他说得更直白：Altimeter 已经把很多东西跑在 Anthropic 上，接进了自己的数据仓库和数据湖，把 OpenClaw 直接放到 Altimeter 的数据集上是不明智的，这是两个根本不同的产品。萨克斯承认这个理由成立，但坚持他问的是另一个问题：Anthropic 是不是给自己留了价格优势。

杰森直接站到了萨克斯的怀疑那边。他进一步说，山姆·奥特曼把彼得招进 OpenAI，目的可能是截胡这个开源项目的下一批天才想法。他列了一串正在围剿或竞争 OpenClaw 的选手：Anthropic 的 Claude 托管 agent（4 月 8 日发布）、Perplexity Computer、2 月 25 日发布的开源项目 Hermes agent、阿里巴巴基于千问的版本、马斯克从 MacroHard（微软的双关）推出的 Grok Computer，以及亚马逊和苹果即将更新、没那么笨的 Alexa 和 Siri，微软那边还按兵不动。

我相信，前沿模型领域现在的头号目标，就是干掉这个开源产品。（杰森·卡拉卡尼斯）

他的担忧落在一个更私人的层面：agent 这一层相当于你的全部生活、全部生意，把它交给 Anthropic 或 OpenAI 是愚蠢的。他甚至点名格斯特纳，说把一辈子积累的知识灌进任何一个大模型，都会让他非常担心。

萨克斯随后抛出一个 yes / no 问题：Anthropic 现在在编程领域是不是主导份额。查马斯说不。杰森说领先但不算主导。格斯特纳说这是个万亿美元的市场，他们今天占不到 10%。萨克斯追问编程 token 的占比，杰森说超过 50%，萨克斯当场定性：那这就叫主导市场份额。格斯特纳反驳说，九个月前所有人都说他们出局了，被 OpenAI 打得满地找牙，现在又有人说他们有主导地位，这是世界上变化最快、竞争最激烈的市场，很难走进任何一家地方法院，说他们已经在亚马逊、谷歌、微软、OpenAI 面前形成了垄断。

查马斯给了一个更冷的判断。他认 Anthropic 有 50% 到 60% 的份额，Codex 用得也很广。但这掩盖了更重要的一点：AI 编程整体还只占广义市场的 5%。白纸从头写的新代码居多，而任何模型构建企业级软件的长期能力「依然很烂」。这个判断来自他走访客户的现场，那些 5000 亿美元的银行、1000 亿美元的保险公司，没有一个会说「开箱即用，就是行」。大部分还是手工调优。

他给出一个画面感极强的例子：有家年收入 1000 亿美元的公司，得把 60 岁的退休老人请回办公室来解读 COBOL 代码。他没有在开玩笑。世界上积累了五十年的技术债，摊开成代码行数可能是几百万亿行的平庸乃至糟糕代码，再加上一堆遗留语言。99% 的技术债，这些模型现在处理得依然很差。解开这个死结要花几十年，所以关于其他一切的热烈讨论，都不在钱真正所在的地方。

对开源这条线，两人的分歧很清楚。杰森举了 BitTensor 的 Subnet 62 项目 Bridges AI 做例子：花了大约 100 万美元的 TAO 奖励，45 天内做到了 Claude 4 能力的 80%，参与机制像比特币挖矿一样形成飞轮。查马斯则把话说死：任何一家有分量的公司，把生产代码外包给开源项目，「概率为零，永远不会发生」。但他同意杰森另一部分判断：如果资本市场不再愿意开出百亿、两百亿美元的支票，唯一的出路就是彻底分布式，那么一定会出现一个成功的开源预训练项目。

萨克斯做了三点收尾。第一，AI 编程现在可能只占 5%，但会走向 95%，他愿意为此赌任意金额，唯一的问题是时间。第二，如果早期领跑者拥有 50% 到 60% 的份额，就意味着最多的开发者、最多的代码库访问权、最多的训练 token，存在一个让领先者自我强化的飞轮，编程 token 市场有可能被垄断。第三，也是他真正的落点：这些公司接下来的动作要干干净净，别做政府日后用事后视角判定为反竞争的事，别歧视别人的产品，定价要公平。他不指控任何人违规，只是提醒将来会有人回看这段历史。

一月加 40 亿，二月加 70 亿，三月加 100 亿

Anthropic 的营收 run rate 突破了 300 亿美元。时间线是这样：2023 年初开始对 API 收费，2024 年做到 10 亿 run rate，2025 年 2 月发布 Claude Code，发令枪响，2025 年中到 40 亿，2025 年到 90 亿，再往后几个月，也就是 2026 年 4 月，到了 300 亿。达里奥几个月前宣布，已有超过 1000 家企业客户年付超过 100 万美元。

格斯特纳补了一张图：1 月增加了 40 亿年化 run rate，2 月增加了 70 亿，3 月增加了 100 到 110 亿。单是一个月增加的量，就相当于 Databricks 加 Palantir 的营收总和。公司原计划在年底达到 300 亿美元的 exit run rate，结果 3 月就到了，而且 4 月很可能还在继续。

他的解释是，模型和产品能力刚刚跨过一个门槛，接近 AGI，所有人看到的第一反应是「这太好了，我必须拥有」。这笔钱不再走 IT 预算，而是劳动增强和劳动替代的预算。他还给了一个参照：Cowork 在当前阶段的增长速度比同期的 Claude Code 还快。

它揭示的是，我们面对的是一个近乎无限的 TAM。智能的 TAM，和我们以前见过的任何东西都根本不同。（布拉德·格斯特纳）

他强调推动力来自需求侧：公司自己在要求这个产品，甚至被产品限流，跟什么神级市场推广没多大关系。他还说了一个容易被忽略的数字：很多大公司 65% 到 70% 的 token 消耗已经是开源模型。也就是说，这轮营收爬坡是在世界已经在用开源的前提下发生的。

杰文斯悖论在这里被他重新定义了一遍：暴跌的是智能的单位成本，跟 token 单价没多大关系，因为模型本身强了太多。他举了个案例，一家大公司今年预计消耗 1 亿美元的 token，对应约 50 亿美元的运营支出，这家公司认为自己接近了就业峰值，但智能消耗还会继续涨。他的结论是，到年底，Anthropic 有可能以 800 到 1000 亿美元营收收尾，而 OpenAI 也在同一波浪潮上，即将发布一个出色的模型，营收也会出现拐点。

查马斯对盈利问题泼了盆冷水。他提到投资圈流传的那张术语阶梯图：不能谈自由现金流就谈 EBITDA，不能谈 EBITDA 就谈毛利，不能谈毛利就谈营收，不能谈营收就谈总预订量。按这个标尺，他认为现在的位置在总营收和净营收之间。市面上还有报道说 Anthropic 报的是总营收、OpenAI 报的是净营收，各自的抽成比例外界并不知道，公司也没给过澄清。他提醒人们，很多人连实际确认营收和 run rate 营收的区别都分不清。

格斯特纳反驳了「毛利为负」的普遍印象。他的论证是，最大的成本输入是算力，而 Anthropic 只有 1.5 吉瓦算力，无论他们做 10 亿还是 800 亿营收，这 1.5 吉瓦都在那儿。所以毛利率是在爆炸式上升，可能是他见过的科技公司里上升最快的。他甚至提了一个概念，叫「意外盈利」：花钱的速度赶不上营收增长的速度。参照系是人数，Anthropic 只有 2500 人，谷歌跨过这个营收门槛时有 12 万人。他还提到推理成本同比下降 90%。至于总营收和净营收之争，他的说法是通过 hyperscaler 分发的部分只占总营收的个位数百分比，按最保守口径把 Anthropic 营收往下调 5% 到 10% 也改变不了大局，这个争论是个干扰项。

查马斯从另一个角度切进来。他说 Meta、谷歌和 SpaceX 这类手握堡垒级资产负债表的玩家，会希望把这件事变成一场资本问题，因为那样他们能控制场上条件。Meta 现在的模型评价是「还行」，但公认性能极强，这正是庞大算力基础设施的优势。如果你是 OpenAI 和 Anthropic，你会希望这件事越高效越好；如果你不是，你会希望它越烧钱越好。他提醒所有人，Facebook 和谷歌当年不管做到 10 亿营收的路径如何，三年内就盈利了，之后再没回头看过。

OpenAI 处于 FUD 顶峰，但别急着下结论

杰森描述的状态是：OpenAI 那边不叫溃败，但充满了焦虑，员工在流失，很多人在怀疑消费者优先的策略是不是赢的那条。公司关掉了 Sora，解开了迪士尼的交易，试图重新聚焦。二级市场上，OpenAI 的交易价低于上一轮估值，Anthropic 则显著高于 3800 亿美元。

格斯特纳的评价格式很讲究，先给 Anthropic 应得的巨大赞誉。去年他们被彻底排除在游戏之外，过去十二个月打了回来，最近九十天把 OpenAI 打得很难看。Anthropic 做的是减法：不做多模态，不做视频，不做硬件，不做芯片，不建数据中心，只专注编程和 Cowork，并认定这是通往 AGI 和 ASI 的路径。2500 个人朝同一个方向划桨。但他说，严重低估 OpenAI 是不明智的。

我们现在处在 OpenAI FUD 的顶峰。但这一切始于优秀的研究员和优秀的模型，Spud 即将发布，我认为它会是一个出色的模型。（布拉德·格斯特纳）

他说已经有人预览过 Spud，反馈是与 Mythos 同一水平，而且打包方式很好用。他反复强调一个判断：这个市场远谈不上零和，智能的 TAM 比过去二十年见过的任何 TAM 都大得多，只要站在浪上，公司就会很大。他自己现在是 OpenAI 股票的买家，尽管承认那边正在经历真实的自省，研究团队和产品团队感到难堪，想做回自己。他也提醒别把 Meta、谷歌、马斯克排除在外。

Polymarket 的赔率被摆了出来：2027 年前 IPO，SpaceX 95%，Cerebras 94%，Anthropic 51%，OpenAI 44%。Anthropic 上市后市值，78% 的概率高于 6000 亿，19% 的概率不上市。格斯特纳自曝首次投资 Anthropic 是在 1300 到 1500 亿美元那一轮，并说自己在两家公司都投了几十亿美元。

他还描绘了当下风投的处境：IGV 指数年内跌 30%，软件股一片狼藉，风投现在极度恐惧，除了前沿模型、SpaceX、军事现代化之外几乎不敢下注，因为很难找到一个能躲开 AI 冲击、终值可预期的标的。他自己的打法是杠铃策略，重仓前沿公司，再用小团队押注在 AGI 世界里依然有护城河的生意。

萨克斯对软件公司的判断偏温和。他说市场可能有点过度悲观，软件确实会变得又便宜又容易做出来，但这本来就不是很多软件公司的竞争优势，所以现在有点把孩子跟洗澡水一起倒掉，企业软件里可能有价值洼地。他把真正有意思的问题落在价值捕获的层次上：最早只有芯片层，英伟达是第一个靠 AI 值上万亿美元的公司；然后 hyperscaler 受益；现在轮到模型层，Anthropic 和 OpenAI 都会是大赢家；下一个问题是应用层，价值会被模型公司吃掉，还是会出现一批被超充的应用公司，Palantir 已经算一个。查马斯的回答是：太早，还看不出来。

伊朗停火，市场只跌了 5% 到 7%

停火开始两天，JD·万斯、维特科夫和库什纳去伊斯兰堡谈判。复活节那天，特朗普发帖要求打开海峡，说否则「疯狂的王八蛋们会活在地狱里」。周二早上又发了一条，说「整个文明今晚会死去，永远回不来，我不想这样，但很可能就是这样」。当晚 6 点 30 分，他宣布只要伊朗开放海峡，就同意两周停火，并说收到了伊朗的 10 点提案，认为可以作为谈判基础。同时，内塔尼亚胡把停火理解成了在黎巴嫩的另一个版本，十分钟内扔了 160 枚炸弹。

萨克斯先做了免责声明，说自己不在白宫外交政策团队里，上次在节目里评论战争，莫名其妙上了国际头条，被写成「特朗普顾问说」，而这不是技术问题，所以受到限制。但他明确说，有停火是好事，去伊斯兰堡敲定是好事，总统促成停火值得大加赞赏，因为这些战争会自己有生命，会不断往升级阶梯上爬，很难拔出来。

格斯特纳引用了他 3 月 4 日的推文，把它叫「特朗普主义」：大规模摧毁军事能力，杀掉制造致命武器的人，撤出，保留必要时再来一次的权利，零努力去建麦迪逊式民主，伊朗自己决定接下来怎么办。市场的反馈是，去年关税那轮纳斯达克从高到低回撤 15%、盘中跌 22%，而这轮伊朗期间标普和纳斯达克只跌了 5% 到 7%，现在基本已经反弹回开战前的位置。他读出的信号是，尽管特朗普的推文把很多人吓得不轻，但人们已经认定，他说要撤就会撤。他还说，如果这两件事都落地，乌克兰和俄罗斯也接近协议，委内瑞拉进展不错，古巴可能也有消息，那市场就会起飞。

杰森把讨论拉回到「为什么打这一仗」。《纽约时报》的「Inside the Room」报道称，2 月 11 日内塔尼亚胡在白宫给特朗普提了四部分打击伊朗的方案，万斯警告这可能引发地区混乱、撕裂 MAGA 2.0 联盟，鲁比奥反对政权更迭但对轰炸基本中立，幕僚长苏西·怀尔斯担心中期选举前的油价，参谋长联席会议主席丹·凯恩对以色列的方案有一句评价：「长官，以我的经验，这是以色列人的标准操作，他们会过度推销，方案往往并不成熟，他们知道需要我们，所以才拼命卖。」

查马斯的回应很干脆：决定者是美国总统，外国领导人不会在美国拍板。他更愿意看市场的定价，认为市场已经把这件事定成了一个小插曲，说明我们大概处在终局。他还加了一句他自己的判断：如果他是以色列，他会非常担心，如果不尽快找到下台阶，失去美国这个可靠的盟友的风险就会上升，这对以色列的伤害远大于对美国。

杰森总结说，美国老百姓不想打这场仗，普遍觉得被以色列拖了进去，觉得内塔尼亚胡的影响力太大。他承认自己采访过的犹太裔美国人中有不少人认为，内塔尼亚胡在加沙、黎巴嫩、伊朗的所作所为已经过头，正是这些行为造成了当下的反犹情绪。格斯特纳的态度是交给历史评判，并提醒人们什么都不做同样有巨大风险，他选择保持乐观。萨克斯则提到以色列政治家纳夫塔利·贝内特发推引用的民调，显示以色列在美国正变得越来越不受欢迎，贝内特对此表示担忧。萨克斯说这是以色列该考虑的事，如果以色列站到停火身后，会改善它的受欢迎程度。

节目的尾声有一段关于 X 自动翻译功能好处的闲聊，以及查马斯提到的一位在赌场听了他的话下注输钱、他反过来资助了对方两个女儿大学账户的段子，这些和主线关系不大，略过。

下面是从这期内容里能直接拿走的几个动作。

  • 如果你负责任何有一定规模的代码库，把接下来几个月当成一个一次性的窗口期。让模型跑一遍自家系统的漏洞扫描，优先处理那些沉睡多年的老组件，尤其是基础设施和网络相关的部分，趁先进能力还没普及到攻击者手里。
  • 别把 Mythos 的叙事当成纯粹的技术新闻，也别当成纯粹的营销。用同一套模板去看待所有「太危险所以不发布」的公告：先看它有没有给出具体的漏洞清单和修复路径，再看它有没有把关键行业（能源、航空、金融基础设施）拉进合作名单。名单选谁，往往比公告说什么更能说明意图。
  • 如果你是开发者或团队负责人，把你最核心的知识资产和业务逻辑留一份在自己手里。agent 这一层会成为你的全部工作流入口，把它完全托管给任何一家前沿模型公司，等于把命脉交出去。
  • 对投资者来说，这期最有价值的信息不是 Anthropic 的营收数字，而是格斯特纳说的那句「杠铃策略」。当下的风投环境下，能躲开 AI 冲击、终值可预期的标的越来越难找，要么押最前沿的公司，要么押在 AGI 世界里依然有护城河的小团队，中间地带最危险。
  • 关注软件股的错杀。市场对「AI 让软件变得又便宜又好做」的恐慌，正在把一批本来靠渠道、数据、客户关系建立护城河的公司一起打折。萨克斯的判断是这里可能有价值洼地，前提是你能分辨哪些公司的护城河本来就跟「写代码这件事」无关。
  • 看伊朗局势，盯市场，别盯推文。格斯特纳给的参照很实用：去年关税那轮回撤 15% 到 22%，这轮只有 5% 到 7% 且已经修复，市场的定价已经说明了它对「特朗普最终会撤」的信心。上行风险（乌克兰、委内瑞拉、古巴）和下行风险一样真实，值得同时盯着。
