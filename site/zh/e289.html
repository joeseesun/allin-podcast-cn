一位在 Anthropic 只工作了六个星期的研究员离职，在 X 上发帖说“造 AI 的人真心相信 AI 会在十年内杀死我们所有人”，这条帖子两天内拿到超过一亿浏览。Anthropic 负责对齐科学的伊万·胡宾格（Evan Hubinger）随即回复表示认同，还给出一个数字：他个人认为十年内人类灭绝的概率超过 10%。两条帖子合计两亿浏览。

大卫·萨克斯（David Sacks）开场就抛出他的判断：这看起来更像一场组织严密的公关运作，从发帖、放大到媒体配合，每个环节都有痕迹可循。他的证据链是：发帖账号此前几乎零动态、零粉丝，却在一天之内获得巨大分发；前三到十五分钟内放大这条帖子的，是三家组织严密、资金充足的末日论团体；而且《华尔街日报》的报道发布时间，比推文风暴本身还早了几分钟，说明媒体拿到了 embargo 简报，只是搞错了发布时间。

“媒体叫他吹哨人，但他吹响了什么哨？给我们看看数据、看看报告、看看公众原本看不到的内部泄露。什么都没有，全凭感觉。”（大卫·萨克斯）

谁在放大：三家末日论团体和共同的出资人

萨克斯点名了三个在最初十五分钟内参与放大的组织：Encode AI 的总法律顾问内森·卡尔文（Encode 是推动加州 SB 53 州级 AI 法案的主力）、AI Policy Network 的政策负责人彼得·威尔德福德（推动联邦层面设立 AI 监管部门）、AI Futures Project 的负责人丹尼尔·科科塔约（恰好在同一时间上了一个 Joe Rogan 节目，用词几乎一模一样）。

这三家组织的共同出资人是简·塔伦（Jan Talen），EA（有效利他主义）圈子里的大金主之一，同时也是 Anthropic A 轮的联合领投人。杰森·卡拉卡尼斯（Jason Calacanis）补充了另一个出资人：达斯汀·莫斯科维茨，他和山姆·班克曼-弗里德一起领投了 Anthropic 那轮 EA 资金。这些 A 轮投资人正站在赚取数千亿美元回报的关口上，而他们资助的团体在推动对 Anthropic 有利的监管框架。

伯尼·桑德斯转发了这条推文，并以此为由推动禁止超级智能、暂停 AI 开发的立法。伊利诺伊州州长普利兹克也跟进说“该把警报拉得更响了”。萨克斯认为这些政客未必知情参与了运作，更可能是这些团体早已与其幕僚建立了管道，内容一到手就立刻转发了，因为它符合各自的政治议程。

弗里德伯格：末日叙事是人类最古老的控制工具

大卫·弗里德伯格（David Friedberg）没有停留在“这是不是运作”的层面，他把这类叙事放进一个更长的历史序列里：阿尔·戈尔的《难以忽视的真相》引用的 IPCC 预测后来被证伪了不少假设；福奇说新冠会杀死所有人，结果是全球封锁、政府疯狂开支、通胀飙升和今天的债务螺旋；三里岛事故之后美国 hysterically 停掉了核电，如今美国建一吉瓦核电要花约 150 亿美元，法国是 40 亿，中国是 10 亿。

“人类是住在洞穴里的灵长类，我们天生害怕未知、看不见、没去过的地方。我们要去的是一个从没去过的地方，所以可怕。有人说地是平的、往西航行会掉下去，直到哥伦布驶过去，新大陆才被发现。”（大卫·弗里德伯格）

他指出这类“存在性威胁”叙事的结构是固定的：告诉你你会死，然后说只有把权力交给我、让我来控制这件事，我才能保护你。从最早的宗教机构到今天的 AI 监管呼吁，逻辑一脉相承。数据中心的民调支持率是负 80，说明社会恐慌机制已经被充分激活。

弗里德伯格还给出一个关键的技术论点：递归自我改进（RSI）需要的只是一些芯片、电力和互联网连接，不需要任何政府批准。如果美国停下来，别的国家会做。届时美国就成了那个从没见过文明的亚马逊部落，文明在别处演化，而它被留在原地。所以“预防原则”在这个问题上执行不了，唯一现实的路径是参与竞争。

四个人玩了“我们怎么死”游戏，没人能拼出完整剧本

弗里德伯格提议每个人都钢铁人（steel man）一下“10% 灭绝概率”论，结果四位投资人的答案都各自暴露了论证的断层。

杰森选了《终结者 2》剧本：Claude 接入军方做自主武器，天网式地触发核战。查马斯·帕里哈皮蒂亚（Chamath Palihapitiya）的版本是 AI 入侵联网的生物反应器和机器人，用前体材料合成一种半衰期极长、能进喷射气流、吸入即死的空气传播病原体，他自己承认这个剧本“很可悲，中间步骤多到不可信”。弗里德伯格选了关停金融网络，但随即承认金融机构早有核战级别的预案，物理硬拷贝资产记录存放在多个隔离地点。萨克斯则指出气隙隔离（air gap，不联网）和人在回路（human in the loop，比如核弹的双钥匙制度）这两道闸门本身就挡住了大部分剧本。

真正的核心论点来自 RSI：对方声称能力提升的速度很快会达到“AI 全自动完成 AI 研究员的工作”，自己设计训练循环、自己按下按钮、一路起飞。萨克斯的反击是，Anthropic 联合创始人杰克·克拉克（Jack Clark）自己区分过“平凡 RSI”（AI 帮研究员写 80% 的代码，加速开发，这确实在发生）和“RSI 极端主义”（完全没有人类在回路）。从前者跳到后者再跳到“所有人都死”，中间有五十个路标需要逐一论证，而末日论者从不展开中间步骤。引用比尔·格利的话：把中间步骤和每一步的干预手段列出来，这个论证就开始散架。

现场的搞笑注脚：四个人一边争论人类灭绝，一边吐槽 AI 连酒店房间都订不了、Python 自动补全还没做好。查马斯的总结：“订不到酒店房间，但它要杀死我们所有人。”

末日言论撞上静默期：Anthropic 的 IPO 死结

查马斯把讨论推向了最有现实杀伤力的地方：Anthropic 正在进行 S-1 申报流程，此时员工在内网外网集体背书“公司产品可能终结文明”，这在证券法上是什么性质？

他举了两个历史案例。Google 上市前，佩奇和布林在《花花公子》的采访恰好落在静默期窗口内，差点导致重新申报；查马斯自己在 Slack 上市时上 CNBC 顺口说了几句 Slack 的好话（只是谈网络效应），法务团队被迫把采访打印出来塞回 S-1 并逐条免责声明。这次的严重程度远超那两例。

从法律角度看，真正的爆点出在胡宾格的背书上。萨克斯强调，胡宾格是仍在职的对齐科学负责人，属于公司高管序列，他给“灭绝概率超 10%”背书，等于公司内部人士在静默期内发表了对核心产品的重大风险陈述，离职者本人的推文反倒还在其次。正常公司的法务部在 IPO 前会挨个叮嘱员工闭嘴，苹果的做法是全公司只有蒂姆·库克和公关部门能代表公司发言。而 Anthropic 内部是一堆人公开转推、背书。

“你要么公开切割，说这个人是入门级、满嘴科幻 hyperbole；要么认同他，那么伯尼·桑德斯也许是对的，应该冻结开发，那你怎么还能以万亿美元估值上市？”（大卫·萨克斯）

查马斯的分析是管理层被困死了：切割会引发内部认同末日论的那批员工造反，不切割则 S-1 的风险披露过不了关。投资者如果真信披露，会要求巨大的估值折扣；产品责任的长尾更是无底洞，如果公司自己承认产品可能毁灭文明还继续更新发布，将来任何企业事故、任何一起与 AI 相关的自伤案件，原告律师都可以拿这些推文做证据。他把这比作菲利普·莫里斯：“我们知道香烟会杀死你，我们会这么说，但不做披露，先上市，以后再说。”

萨克斯点出 Anthropic 历史上化解这种张力的惯用话术：在别人手里，前沿 AI 太危险不能开发；在我们道德高尚的手里，它是安全的。所有人都看得出这是最露骨的垄断诉求，没人会为“你们最讲道德”就送出前沿 AI 的专营权。

节目录制中途，杰森插播一条突发新闻：黄仁勋正在高盛会议上发言，直接说这位离职者的言论“荒谬且严重不实”，对行业的各种安全工作“傲慢且无知”。杰森的追问是：黄仁勋能说，Anthropic 为什么不能？

OpenAI 解了两百年老题，但你的提示词可能成了它的养料

OpenAI 宣布用约 1.3 亿美元的计算量、一万个相互协作的 agent 解决了纳维-斯托克斯方程（Navier-Stokes，描述流体运动的偏微分方程，飞机、管道、气象模型的地基）。弗里德伯格算了一笔账：这些 agent 的工作量折合人类以每分钟 40 词的速度做数学推演，大约相当于五万到五十万年的人类工时，保守砍一个数量级也是数万年。

“这不是数学之神显灵。每一轮 agent 之间的消息都有记录，人可以读、可以理解。AI 是给人类提供杠杆的引擎，把几万年的工作压缩到几分钟或几秒。”（大卫·弗里德伯格）

但故事有个污点。最早在这个问题上取得进展的两位数学家（Levent 和 Tristan）指控 OpenAI 用他们自己的使用数据抢跑。OpenAI 的官方声明措辞是：“虽然可能性不大，我们不能排除源于他们使用我们产品的去标识化数据帮助改进了模型。”翻译过来就是：不保证。

杰森倾向于相信 OpenAI 研究员诺姆·布朗的否认（没人会去翻看用户的具体 prompt），更可能的解释是 OpenAI 听说有人在逼近突破，直接砸算力抢了先，而萨姆·奥特曼也确认过他们听说 Anthropic 接近了才决定出手。但不管这次是不是真的，机制上的问题成立。

去标识化是块遮羞布：ZDR 保护不了你的 IP

弗里德伯格讲了自己的亲身经历：他们在某个冷门科学领域问模型一些新颖问题，模型会说“这个思路很有意思，从没人这么想过”；过段时间换账号问新版本模型，它直接复述了之前对话里那个独特思路。他知道那个领域没有新论文发布，唯一的解释就是他们的对话被拿去训练了。去标识化只剥离“这是谁、哪家公司”的信息，但解题思路本身就是 IP，它照样进入模型的参数，之后扩散给所有用户。

查马斯把企业级的应对方案讲得很具体。所谓零数据保留（ZDR）只是商业上的“尽力而为”，聊天窗口里随手点个赞都可能让数据漏进训练语料。真正敏感的数据，正确做法是找一家可信的供应商（AWS，或新势力里的 Nebius），架自己的裸金属硬件，跑自己的模型（可以是开源模型，也可以是托管在自己 VPC 里的 Claude），一切都归自己控制。走标准 API 价目表的懒人方案，等于闭眼赌自己的核心 IP 不泄漏。他预言明年就会有几位 CIO 因为这个问题被公开开除，因为审计委员会、风险委员会已经通过 EY、德勤这些顾问了解到 ZDR 是瑞士奶酪，一旦某天发现自家 IP 出现在模型另一端，股东诉讼就会压过来。

萨克斯透露自己刚订购了两台 Mac Studio，准备跑开源模型、把敏感工作从 Claude 迁走。查马斯泼了盆冷水：单人用本地模型可以，但几百人的公司需要多人协作、知识库、记忆，那就要机架服务器了。

更深一层的问题由杰森点出：只要闭源前沿模型保留进入每一个垂直应用的权利（Anthropic 已经发布了 Claude Code 和 Claude Design，把最大的客户 Cursor 直接 rug pull 了），它们就是在提前宣战自己的客户。投诉的数学家自己也说不清是不是真被抢跑，因为他们用的工具的母公司同时在和他们赛跑。在反垄断和隐私立法到位之前，“不要把你的 alpha 喂给凯撒”（借用 Alex Karp 的说法）是唯一自保手段。杰森还呼吁把 AI 聊天数据的隐私保护至少提升到邮件的级别：目前调取你的 AI 对话只需要传票，不需要搜查令和合理理由，而人们正在把 AI 当律师、医生和心理治疗师用。

Nike 被踢出标普 100：2000 亿美元市值是怎么蒸发的

六十岁的 Nike 连续十八年后被移出标普 100，替换它的是朋友尼凯什执掌的 Palo Alto Networks。数字很惨：2021 年巅峰市值 2640 亿美元，2024 财年营收巅峰 510 亿美元，此后营收下滑约 10%，中国销售跌 30%，连续多个季度下滑，被安踏和李宁蚕食，股价从峰值跌掉 80%，约 2000 亿美元市值消失。

杰森把责任拆成三块。第一是 2020 年上任的 CEO 约翰·多纳霍激进推行 DTC 直营战略，主动把货从零售伙伴的货架上撤下来，腾出的位置全部送给了 HOKA 和 On Running。第二是营销彻底变味：从 Michael Jordan 时代的“Just Do It”，变成连 Dylan Mulvaney 都能上广告的路线，杰森称之为“Go woke, go broke”的又一个案例，他认为从 Colin Kaepernick 那支旧金山广告开始就是转折点。第三是内部重组，把按运动项目划分的部门（篮球、橄榄球、游泳）改成按人群划分（男、女、童），理由完全看不懂。

查马斯的归因更本质：Nike 的北极星曾经是“通过运动体现的精通与卓越”，Jordan 是它，Tiger 是它，Serena 是它，Sampras 是它。你不会去买一个你不渴望成为的人穿的衣服。他自己曾是 Nike 死忠，最后换到 On 的原因只有一个：Roger Federer，他所做的一切看起来毫不费力。弗里德伯格补充了最朴素的一层：他以前只买 Nike，后来鞋六周就坏、跑步伤膝盖，去 REI 试了双 Brooks 就再没回头。Brooks 是伯克希尔旗下的子公司，连续九年双位数增长做到 16 亿美元营收，CEO 说巴菲特每年只给一句指令：让产品比去年年底更好，业务自然会长。Nike 反着来，从做产品转向讲叙事，讲它以为观众想听的叙事，这和百威淡啤犯的是同一个病。

查马斯认为 Nike 是一根压紧的弹簧：只要重新锚定“精通与卓越”，重新回到有消费力人群的零售渠道，几千万人会回来。杰森补了一刀说他们该把广告语改成“Do it or don't”，随后这个梗被四个人玩到了节目结束。

行动结论

  • 处理敏感数据的企业和个人：立刻审计你和闭源前沿模型的接入方式，ZDR 不构成保护。敏感 IP 要走自建 VPC、裸金属或开源模型（DeepSeek、Kimi、Llama 等）路线；个人用户可用本地模型加 Mac Studio 类设备处理最核心的内容。
  • 投资视角：Anthropic 的 IPO 文件值得逐字读风险披露部分，员工公开背书的“10% 灭绝概率”如果未充分披露，既是估值折扣的理由，也是长尾产品责任诉讼的引信。同时关注企业级“AI 主权”供应商（Nebius、Fireworks、自建方案集成商）和自研模型的 AI 应用公司（如 Harvey 基于 Kimi 的 Tenet）的结构性受益机会。
  • 创业者：如果你的产品建立在闭源前沿模型 API 之上，记住模型厂商保留随时下场竞争的权利，Cursor 的遭遇随时可能重演。护城河要么是自有模型，要么是模型厂商无法复制或不愿进入的数据与工作流。
  • 判断 AI 政策新闻的方法论：看到病毒式传播的“AI 灭绝论”，先查三件事：账号历史、最初十五分钟谁在放大、传统媒体是否提前拿到 embargo。这套框架这次全部命中。同时用预测记录校准信源，这一批末日论者此前对 GPT-2 危险性、推理模型、网络攻击、大规模失业的预测，目前战绩是零比四。
  • 做品牌和产品的团队：Nike 的教训是叙事替代产品之日就是衰败之始。巴菲特式的“今年把产品做得比去年好”仍是复利的最短路径；北极星一旦从“卓越”漂移到“表态”，2000 亿美元的市值就是这么没的。
