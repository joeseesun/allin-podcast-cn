本周的 All-In 是老朋友回归局：Gavin Baker（Attar Capital 创始人，管理约 40 亿美元资产）时隔多年再次坐上主位。他是黄仁勋点名邀请过的唯一一位买方公开股票投资人，认识黄仁勋二十五年，聊起英伟达的账本比绝大多数分析师都有底气。杰森·卡拉卡尼斯（Jason Calacanis）主持，查马斯·帕里哈皮蒂亚（Chamath Palihapitiya）和大卫·弗里德伯格（David Friedberg）坐镇，萨克斯继续缺席。

这期从英伟达应收账款争议、CoreWeave IPO，一路聊到 AI 智能体（Agent）、对华芯片管制、关税的终极盘算、Signalgate 的法律边界，以及萨尔瓦多监狱引发的人权辩论。中间几位主持人几度吵到面红耳赤，恰恰是这档节目最好看的部分。

英伟达的应收账款问题：黄仁勋在下一盘什么棋

查马斯开门见山抛出市场最热的质疑：英伟达的应收账款从一年前的约 15 亿美元涨到 55 亿美元，累计应收账款已经到 230 亿美元，涨幅超过营收增速。市场上有不少人怀疑英伟达在做“资金循环”（round tripping）：投资 CoreWeave 这类新兴云服务商（neocloud），对方再拿钱买英伟达的 GPU，营收看着漂亮，实际上是左手倒右手。

Gavin 的回答很直接：就算英伟达一分钱都没投给 CoreWeave 和其他新兴云厂商，营收也不会有任何影响。这些 GPU 本来就会卖给 Meta、微软、亚马逊、特斯拉。英伟达投资这些小云厂商，目的在别处：三年前云计算是亚马逊、谷歌、微软三家稳定寡头的天下，对英伟达来说只有三个大客户非常危险，大客户议价能力太强。而且 2023 年抢购 GPU 最疯狂的时候，每家巨头都想搞自己定制版的英伟达服务器。

英伟达的做法是给出一套标准参考设计。像 CoreWeave 这样采用标准设计的厂商，GPU 上架速度快得多，跑英伟达全家桶芯片也更顺。结果是三大云厂商在英伟达收入中的份额被稀释，买家群体更分散，单一客户的议价权下降。查马斯听完后给了一个精彩的类比：这和英特尔当年搞“Intel Inside”是一回事。回头看不一定是必需的，但它扶持了生态、分散了买方势力，让更少的人能拿捏英特尔。

那应收账款暴涨怎么解释？Gavin 认为要放在产品切换的背景下看。从 Hopper 到 Blackwell，是半导体史上规模最大的产品换代，地球上唯一有可比性的先例是 iPhone 的年度升级。而且这次代际切换的难度前所未有：

  • Hopper 机架约七英尺高、一千磅重、功耗 60 千瓦（相当于 60 户美国家庭），风冷散热；
  • Blackwell 机架三千磅、八英尺高，同样占地面积下重量三倍、功耗翻倍到 120 千瓦，并且改成了液冷。

Gavin 的类比是：这就像换新 iPhone，但换机条件是你不仅要换接口，还得装新发电机、新锅炉和整套全屋加湿系统。客户在机器安装调试完成前不愿意付款，应收账款自然堆积。他给了一个明确的观察指标：如果这个趋势延续到 7 月之后还没回落，那就真值得担心了；但在这样一个产品周期里出现，是最可理解的时点。

“应收账款上升从来都不是好事。但如果要挑一个它最可以被理解的发生时刻，那就是现在。”（Gavin Baker）

CoreWeave IPO：被市场集体看空的公司，可能没那么“商品化”

录制当天，CoreWeave 正在 IPO 定价：原计划募资 20 亿美元，最终下调到 15 亿美元，估值 230 亿美元。杰森列出市场看空的清单：去年营收 20 亿美元（同比增长 8 倍）但背了将近 80 亿美元债务；微软一家客户占营收超过 60%；英伟达持股 6% 并贡献 15% 收入。X 上的投资人情绪一片唱空：商品化生意、高杠杆、高资本开支、客户集中、毫无差异化。

Gavin 的第一层回应针对“算力过剩”的担忧：DeepSeek 发布之后发生的事，恰恰说明现在算力严重不足。中国正在买下能买到的每一块 GPU，中国最大的服务器厂商之一前几天警告国内即将出现 GPU 短缺，DRAM 内存价格天天在涨；OpenAI 前一天刚宣布限制新的图像生成服务，理由就是 GPU 不够。他还点出一个结构性因素：所有人都被困在囚徒困境里。你是 Meta，如果你不买 Blackwell 而谷歌买了，对方的 AI 就比你强很多，你可能永远追不上。所以不管多贵都得买。

针对“CoreWeave 是商品化生意”这个共识，Gavin 讲了一段零售业的道理：

“在美国，随便挑一个零售品类，如果你能在 50 个消费偏好各异的州把 1000 家店都开得灯火通明、干净整洁、货架充足、员工友好，你就能做出一家价值远超 100 亿美元的公司。听起来简单，但做到的公司屈指可数。”（Gavin Baker）

他的观点是：运营超大训练集群这件事，被严重低估了难度。让几万块 GPU 同步运转，GPU 会熔化、线缆会松动、一出错就丢一批训练数据，能把这个活干好的公司，地球上没几家。杰森补充了历史上被华尔街看走眼的先例：AWS 刚推出时，很多人认为“谁敢把计算交给亚马逊”，微软宣布转型云计算时也因为从轻资本模式转向重资本模式而备受争议。华尔街的共识错过又不是第一次。

查马斯罕见地全盘附和：CoreWeave 是一家好公司，配得上成功。Gavin 还补了一句：除了谷歌收购 Wiz，CoreWeave 自己买下 Weights and Biases 也是一笔很有意思的收购，某种程度上把自己进一步“非商品化”了。过去一个月大公司并购小公司的数量在加速，只是标的都不是上市公司，所以市场没太注意。杰森把这归功于监管环境的松动：M&A 和 IPO 市场正在回暖，这对市场信心是好事。

出口管制、Manus 与 Agent：算力是下一个十年的硬约束

话题转向中美 AI 竞赛。查马斯注意到两天前美国把一批公司加入了出口管制清单，不少在量子计算和英伟达生态圈内，目的明显是防止下一代 GPU 直接或经第三国流入中国。Gavin 对管制的实际效果持怀疑态度：如果美国连非法毒品都拦不住，Blackwell 这种体积小、单位价值高得多的芯片更难拦。中国是铁了心要把 GPU 弄进去的，这本质上是猫鼠游戏，直到出现某种大交易（grand bargain）。

但杰森追问了更关键的一层：这种挤压策略的副作用是什么？Gavin 承认，管制确实给美国制造了理论上的优势，但代价是给中国发展自己半导体生态制造了巨大动力。需求是创新之母，出口管制正在逼迫中国在算法层面真正创新，DeepSeek 已经证明了这一点。查马斯补刀：“他们现在就在做。”

那中国造出自己的英伟达的概率有多大？Gavin 给出了时间分层的答案：五年内，概率为零；十年尺度上，谁也说不准。关键的不对称在于：对中共来说，十年不长；对美国来说，十年是永恒。

“五年内我觉得没戏，这真的非常非常难。但十年呢？如果你是中共，十年不算长。如果你是美国，十年就是一辈子。”（Gavin Baker）

紧接着聊到 Manus（当时还在内测的 Agent 产品）和 Agent 革命。Gavin 认为有两件事值得关注。其一，Anthropic 开发的模型上下文协议（Model Context Protocol， MCP）刚被 OpenAI 采纳，很可能成为行业标准。Stripe 这类服务只要接入 MCP，任何遵循该协议的模型都能直接调用，Agent 的可用性和标准化问题一下子被打通了。其二，如果 Agent 成真，对就业确实是坏消息，但真正的限速因素是算力。一个人人随时都有 Agent 干活的世界，需要在地面上建成的算力远超现有供给，这就是 OpenAI 谈 Agent 定价 2000 到 2 万美元一个月的原因。

弗里德伯格在这里提出了全场最反共识的观点。他认为 Agent 的真正价值不在替代客服、替代简单工作这些“显而易见的应用”上，而在于解锁今天根本做不了的复杂项目。他的例子很有画面感：想在海底下建一座植物育种设施，今天你得雇海洋工程师、材料科学家、物理学家、施工项目经理，一大堆稀缺专家。但有了 Agent，两三个人就能让智能体把项目计划、每一步的规格、成本、工作量全部拆解出来，原本做不了的项目变成了现实。

“加州高铁预算膨胀到上千亿美元，毫无产出。如果用 Agent 来组织和运行这个项目呢？也许成本就能压到让这个项目真正落地的水平。”（大卫·弗里德伯格）

查马斯则把镜头拉到宏观层面，做了一段经济学推导。投资的本质是追求回报率，而回报率取决于利润率：300 人的公司创造利润的难度远高于两三个人。中国面对美国在位者的战略，和创业公司面对巨头是一样的：用极限的成本破坏力打穿对方的护城河。SaaS 软件这个他口中的“软件工业复合体”是 3.5 到 4 万亿美元的产业，每年增长 10%，即每年新增 3000 亿美元所谓“企业价值”，但很多客户会说这些价值并没有真正被创造出来。如果 Agent 能把做一件事情的运营成本（OpEx）降低一到两个数量级，三人的团队就能撕开这个万亿美元经济体的侧翼。他强调，风险不一定来自中国，但很多这类替代方案会来自中国。

关税的终局：一场四列火车交错而过的“大实验”

杰森把问题挑明：中国不需要在汽车上赚钱，他们补贴整个汽车产业，打平就行，而美国、德国、日本车企的利润就是他们的机会。那么特朗普政府的关税政策到底要走到哪里？

查马斯先给了一个历史锚点：他在 YouTube 上偶然刷到 1987 年特朗普接受 Larry King 访谈的片段，特朗普在《纽约时报》买过整版广告讲贸易失衡，四十年前就在电视上完整论述过今天这套逻辑。这个人在这件事上极端一致，绝非心血来潮。他引用了当年那段访谈原话：

“我们现在根本没有自由贸易。如果你想去日本、去沙特阿拉伯做生意，美国人几乎不可能。我们以为那是自由贸易，其实不是。”（1987 年的特朗普）

查马斯对关税的定性是：关税是一个校准历史失衡的工具。现实是美国对进口商品征收的关税，长期低于别国对美国商品的关税，目标很简单：你收 5%，我也收 5%；你收 10%，我也收 10%。难点在于，经过二十年被扭曲的全球化之后，做这件事会到处冒出“打地鼠”式的副作用：通胀、报复性关税、消费税，这些都要逐一摆平。

弗里德伯格把政府的完整操作框架拆成了一道联立方程。他先确认了一个重要信息：财政部长霍华德·卢特尼克（Howard Lutnick）明确说过，年收入 15 万美元以下的人将全部免税，弗里德伯格认为这件事百分之百会发生，问题只是时间。他的逻辑链条是：关税从经济中抽走了钱（商品变贵、消费下降、钱进了政府口袋），那就必须同时通过减税把钱还给消费者，让购买力保持稳定。同时政府在砍开支（DOGE），开支降了税基就可以降，再加上去监管让增量资本流向自动化和本土生产，把成本压下来。

“这像一个宏大的经济实验。我的感觉是，有四列高速并行的货运列车，你要在车窗之间传递做三明治的所有配料，最后做出那个通向黄金时代的三明治。”（大卫·弗里德伯格）

Gavin 对这套实验的评估显得老练。他讲了一个海豹突击队员的故事：那位服役十年、派驻过 80 个国家的老兵说，美国所有人的目标只有一个，就是别把美国搞砸，因为美国比世界上任何地方都好太多。所以他给政府的建议是：每次说“关税”这个词，就要把“去监管”说两三次。市场（也许是错的）确信关税是坏的，但所有人都同意去监管是好的，鼓励产业回流最可靠的方式就是降低在美国做生意的难度。

他对政府执行力的判断也有依据。财长斯科特·贝森特（Scott Bessent）是世界上最受尊敬的宏观投资人之一，理论和案例是自洽的；而特朗普本人的特点是“adaptable”（随机应变），中期选举只剩十五个月。所以政府的打法是先干最冒险的事，几个月后如果不行，立刻转向：宣布和各国达成一揽子大交易、宣布胜利、把对美关税降一点、把这边关税升一点，然后退到更稳的地面上去做去监管、平衡预算、减税。而政府最承受不起的是衰退，衰退会瞬间炸掉赤字，所以他们最终会对市场信号保持敏感。

查马斯用数字把赤字问题量化了：约翰·阿诺德（John Arnold）估计今年赤字 1.9 万亿美元，2026 年可能还是 1.9 万亿。卢特尼克的说法是“关税收一万亿，马斯克砍一万亿”，等于平衡预算。但华尔街的聪明钱对关税收入的估算只有 1700 亿到 3000 亿美元，取中值约 2000 到 2500 亿。这就意味着马斯克要找到的钱不是一万亿，是 1.75 万亿。查马斯认为浪费、欺诈和滥用的空间可能比想象中大得多：一家咨询公司 95% 以上的收入来自美国政府的工时材料合同，光这类咨询合同政府每年就付出 650 亿美元，还有刚被取消的对 Stacey Abrams 相关组织 20 亿美元拨款的司法调查。这些加起来，缺口未必填不上。

Gavin 在这里爆了一个很个人化的料：他直系亲属的社会安全号被人盗用，有人在阿拉巴马州用这个号码领失业金，已经持续两年，政府就是止不住。他想说明的是，浪费欺诈并非想象出来的，拜登和奥巴马政府的监察长们自己都说过有几千亿美元级别的问题。他还补了一句很有意思的自嘲式观察：

“历史上从来没有哪位总统像特朗普这样给我加过这么多税。但我真的认为，让普通工薪阶层美国人的生活变好，是他们真诚的北极星。你可以不同意这套理论，可以不同意他们的沟通方式，但意图是好的。”（Gavin Baker）

杰森这段情绪明显上头。他罕见地公开吐槽媒体对 All-In 那两期卢特尼克和贝森特长访谈的剪辑式曲解，并顺嘴说漏了几个自己的政治坐标：他自称独立选民、当年是“never Trumper”，但“如果特朗普身边现在全是温和派民主党人，我可能要重新考虑了”，还补了一句“我没有投票给卡玛拉”。查马斯当场抓住把柄：“你刚刚等于承认投了特朗普。”杰森：“我来自伟大的得克萨斯州，就说到这。”

Signalgate：95 篇报道都没讲的那件更重要的事

周一，《大西洋月刊》主编 Jeffrey Goldberg 被拉进了一个 Signal 群聊，群里是国务卿、副总统、中情局局长、国防部长，讨论的是对也门胡塞武装目标的打击计划、精确目标、时间和顺序。没有人发现群里多了个记者。国防部长赫格塞斯（Hegseth，前 Fox 评论员，杰森特意说明这是事实不是揶揄）从别的系统复制粘贴了作战计划，而剪贴板本身就是信息安全里最经典的攻击面。

查马斯先做了一件所有媒体都没做的事：把这次行动的背景讲清楚。这才是被 95 篇 Signal 报道淹没掉的关键信息。加沙战争之后，伊朗继续资助也门胡塞武装，后者封锁红海和苏伊士运河的关键点位，商船要么绕行好望角，要么冒险穿越。红海和苏伊士的通行量因此断崖式下跌，运往美国的运价上涨 40%，运往欧洲上涨 300% 到 400%。这发生在一个最不能承受通胀和生产力下滑的时点上。而群聊里透露的另一个事实是：英法海军都打不过胡塞，全世界只有美国能出手。美国动手之后，三月份的通行量已经回到一年前的水平，运价、通胀风险、生产力冲击全部被控制住了。

所以查马斯的核心判断是：决策本身重要且必要，问题出在工具上。他给 Signal 案件的技术诊断非常工程视角：Signal 桌面端“完全是垃圾”，而把一个加密通讯应用装到每个端点（手机、平板、家用电脑、办公室电脑、书房电脑）上，等于把一个攻击面扩张成了 N 个。他认为这是一次失误，给“两个 Scaramucci（萨卡拉穆奇，白宫通讯主任任期约 11 天，节目里用作时间单位）”的保质期，不值得要谁的脑袋。

弗里德伯格则把这个事件放进了法律框架。联邦记录法（Federal Records Act）1950 年立法、2014 年针对电子通信修法，要求所有政府官员对活动、决策、政策创建并保存“充分且适当”的文档，配合《信息自由法》（FOIA）接受公众调阅。目前有四个相关诉讼在法院系统里走着，包括 Competitive Enterprise Institute 诉科技政策办公室（2016）、CREW 诉特朗普政府（2017）、司法观察诉国土安全部、国家安全档案馆诉蓬佩奥（2019）。Signalgate 之后，“哪类政府通信必须留档、哪类可以脱机讨论”将第一次获得司法上的清晰边界。

但弗里德伯格本人的立场出人意料：他反对把每一条通信都 FOIA 化。理由是企业管理常识：管理层讨论要不要给某个员工加薪、要不要开除某人，这些过程性对话如果全部可被公开调阅，会严重抑制对话的真实性和效率。他的划线是：决策和行动必须留档可查，通向决策的背景噪音不必。

杰森在这里爆发了全场最激烈的输出。他的立场有三层：第一，用 Signal 谈作战计划本来就违法（联邦记录法摆在那里），个人手机极易被黑，他们明明有 SCIF（敏感信息隔离设施）可用，SUV 和办公室都是 SCIF；第二，这个班子最该做的是认错，结果他们第一时间攻击记者、否认有问题，这是特朗普的标准剧本，而讽刺的是“邮件门”当年正是共和党攻击希拉里的全部弹药，如今是彻底的言行不一；第三，现在必须把所有相关人员的手机做取证 dumping，而政府对此一个字都没交代。

查马斯则替政府辩护了两点：一是没人知道 Goldberg 是怎么被加进去的，可能是被注入到某台笔记本上的，先让政府查清楚，Rubio 和特朗普都承认这是失误了；二是他认为那位主编明知不妥却在群里“潜水”（lurking）多日，伦理标准本身值得追问。杰森当场反驳：Goldberg 搞清楚状况后就退群了，而且如果政府先认错、先攻击媒体的顺序倒过来，根本不会有这场持续发酵的辩论。两个人隔着桌子互喊“你的观点就是错的”，最后以查马斯一句“我爱你”和杰森的爆笑收场，Gavin 在旁边小心翼翼地问了一句“你们的紧张感有多少是真的”。

Gavin 在这段贡献了一个被大家忽略的实质信息：群聊内容显示，尽管外界一直说特朗普政府在向俄罗斯靠拢、要炸掉战后美欧同盟，但聊天里他们明确区分了“我们这一边的账本”，也就是承认欧洲是同一边的；而且 JD Vance 亲口指出，美国只有 3% 的贸易走苏伊士运河，欧洲是 40%，这次打击对美国帮助有限、对欧洲帮助巨大，而这件事欧洲自己根本做不了。Gavin 的结论：美欧“分裂”的口水战被夸大了，台面下美国依然在给盟友干活。

萨尔瓦多监狱：238 人、一部 1798 年的法律和 99.9% 的凶杀率降幅

最后一个话题火药味最重。特朗普政府依据 1798 年的《敌对外侨法》（Alien Enemies Act）将 238 名涉嫌委内瑞拉帮派成员驱逐到萨尔瓦多臭名昭著的 CECOT 监狱。这部法律此前只在真正的战争时期用过：罗斯福用它驱逐过二战时期的德国、意大利、日本侨民。政府称帮派成员是委内瑞拉“故意输入”美国的，构成“掠夺性入侵”。ICE 确认并非所有人都有美国犯罪记录，联邦地区法官已下令暂停驱逐，但政府仍在继续，还发布了高制作的宣传视频威胁后来者，国土安全部长克里斯蒂·诺姆（Kristi Noem）亲自到监狱出镜拍片。

杰森举了三个疑似误抓的例子：前职业球员 Jerfeson Reyes-Barrios，因遭政府酷刑而逃离委内瑞拉的难民，手臂上的皇马纹身被当作帮派标记，他实际比的是“我爱你”的手语；三个孩子的父亲、鞋店销售 Norberto Rodríguez，扑克牌和骰子纹身原本是用来遮前臂伤疤的；化妆师 André Hernández，因同性恋身份受迫害寻求庇护，无犯罪记录，被捕依据同样只是纹身。杰森的立场毫无保留：政府有一种“施虐性的基因”（sadistic nature），这是它的阿喀琉斯之踵，如果继续这样搞，中期选举必输。

弗里德伯格提供了这轮辩论里最扎实的一组数据。萨尔瓦多 2015 年每十万人凶杀率是 103，即每年千分之一的人口被谋杀。政府建起这座不经正当程序（due process）就大规模收押的监狱后，去年凶杀率降到了每十万人 1.9，降幅 99.9%，社会治安彻底翻身。代价是正当程序这个美国价值观，纪录片里不少人后来被证明无辜获释，甚至有一个在监狱里关了一年多的无辜者接受采访说“这值得，街道被清理干净了”（杰森对此的吐槽是：“他可能是想出狱才这么说的。”）

查马斯随即抛出了一个电车难题式的拷问：如果你明天就能在美国复制一套萨尔瓦多式收押制度，效果一模一样，错误率 4% 到 5%，你干不干？弗里德伯格和杰森都明确说不干，不做这种价值交换。查马斯的回答则更冷：他怀疑今天美国的监狱系统里，误押的无辜者比例本来就不止 5%。他还把问题推给了制度本身：“你们知道 238 人里有 3 个被误抓，恰恰说明纠错机制在起作用。你要因为 3 个人推翻整个程序吗？剩下 235 个人怎么办？”杰森的回答是：把 238 人全部关在关塔那摩那种人道设施里，让律师逐案核查，公开每个人的案由，该驱逐驱逐，这中间没有任何成本。他真正反对的点是“送到哪里去”：一个以酷刑闻名的他国监狱，和一个会为监狱拍宣传片、由部长出镜警告“这就是下场”的政府。

Gavin 给这段做了最好的收束。他把整个辩论归结为“目的与手段”（ends versus means）这个经典哲学问题：凶杀率下降 99.9% 是好结果，人权是美国核心价值，两者必须平衡。他的两个具体建议都很务实：其一，对被误抓者要同情，对特朗普竞选时那些被非法移民残忍杀害的受害者家庭同样要同情，两边的痛苦都是真实的；其二，引用马斯克在 DOGE 首场记者会上的话：

“我们会犯错，然后我们会快速纠正。政府只需要说一句：如果我们抓错了人，这很糟糕，我们马上修正。就这么一句话，能给你赢回巨大的公信力。”（Gavin Baker）

弗里德伯格最后补了一个战略视角：政府可能根本没打算把这件事做成常规流程，238 人加上几起误抓，本质是一次“发信号”，让在美帮派成员因恐惧而自行离境，用威慑实现净出清。这解释了宣传视频的存在，也解释了为什么政府不在乎那几个误抓案例的舆论。这个判断没有人接话，但它是整场辩论里最冷的一层解释。

看完这期，几件值得做的事

  • 盯英伟达 7 月的应收账款：Gavin 给出的判断标准很明确，产品换代期内应收账款堆积可以理解，但 7 月之后如果还在涨，就值得重新评估整个 Blackwell 周期的质量。
  • 别把 CoreWeave 当纯商品生意：市场共识是高债、客户集中、无差异化，但运营数万块 GPU 的超大训练集群是稀缺能力。评估这类公司时，看合同现金流的净现值和资产价值，比看情绪化的推特共识更靠谱。
  • 把 MCP 加进技术选型清单：Anthropic 的 Model Context Protocol 已被 OpenAI 采纳，很可能成为 Agent 与外部服务对接的事实标准，做开发者产品的团队越早跟进越主动。
  • 重新想象 Agent 的应用场景：弗里德伯格的框架值得直接套用，别问“Agent 能替代谁”，问“过去因为雇不起 30 个专家而做不了的项目，现在三四个人能不能启动”。生物科技、工程、城市规划领域的小团队创业窗口可能正在打开。
  • 用四件事的联动框架看华盛顿：关税、减税、砍开支、去监管必须同时推进，缺一项整台机器就会失衡。观察政府成色的最好指标是：市场（利率、股市、汇率）一出问题，政策转向的速度有多快。
  • 区分“决策”和“决策的方式”：Signalgate 里打击胡塞本身有充分的战略理由（红海运价、欧洲贸易、通胀风险），出问题的是执行层。对企业也是一样，流程安全事故未必推翻战略，但拒绝认错一定会摧毁公信力。
